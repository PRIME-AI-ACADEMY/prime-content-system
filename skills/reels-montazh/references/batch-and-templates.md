# Пачка рилс, музыка и моушн-шаблоны

## Режим «пачка»: N рилс из клипов за один заход
Для `Reels · M` и `Reels · HF` недели (или «сделай 10 рилс из моих клипов»).

1. **План пачки** в чат: рилс · хук (из D) · какие клипы из `clips/каталог.md` · длина. Клип без пометки «брак», ещё не в `output/used-clips.txt`. Жди «да».
2. **Нарезка**: на рилс 3–6 клипов по 2–4 секунды, лучшая часть клипа (не первые 0,5 с). Каждый: `scale=1080:1920:force_original_aspect_ratio=increase,crop=1080:1920,fps=30,setsar=1`, звук клипа выключить, если сверху музыка. Склейка `concat` через файл-список. Переходы только жёсткие, без эффектов. Итог 7–15 секунд для текстовых рилс.
3. **Текст**: хук и CTA через `tools/build_reel.py` поверх склейки (лица проверяются сами, `.check.jpg`). Если по сценарию есть текст по кадрам: подпись в нижней трети на плашке бренда, 4–7 слов, держится весь кадр.
4. **Музыка** (Шаг ниже), громкость −18 LUFS, затухание 1 с в конце.
5. **Рендер** параллельно, H.264, `ffprobe`. Контактный лист пачки `output/ДД.ММ-пачка/00-обзор.jpg`: обложка и середина каждого рилса.
6. Использованные клипы в `output/used-clips.txt`.

## Музыка: три пути
Спроси один раз, ответ запиши в `profile/paths.md` строкой «Музыка: …».
- **Трендовый звук в Instagram** (лучше всего для охвата): рилс рендерится без музыки или с тихой подложкой, звук человек добавляет в Instagram при публикации. В подписи к файлу напиши «звук добавить в Instagram: спокойный / энергичный».
- **Своя папка `music/`**: треки без авторских прав (YouTube Audio Library, Pixabay Music). Claude подрезает под длину рилс, под голос опускает музыку на −12 дБ (`sidechaincompress` или громкость дорожки).
- **Музыка кодом**: Claude пишет простую фоновую дорожку сам (синтез в Python или в HyperFrames), без авторских прав. Это спокойный фон, хитом он не станет. Сначала 1 пробный трек, человек слушает.

## Говорящая голова
По треку Б основного скилла. Из трёх записанных хуков (урок 11) выбери лучший: самый короткий и чёткий, без запинок. Покажи все три одной строкой каждый, жди выбора.

## Моушн-шаблон под рутину
Цель: формат рилс без съёмки, который рутина делает сама на компьютере (HyperFrames или Remotion): текст и схемы в движении, цифры, интерфейс, списки, до/после.
1. **Референсы**: 3–5 роликов, которые нравятся человеку (выбросы из `исследование/вирусные-рилс/`, свои находки). Опиши словами, что общего: ритм, шрифт, движение, сколько текста на экране.
2. **Шаблон v1** на дизайн-системе: композиция HyperFrames 1080×1920, все тексты и цифры вынесены в переменные (`data-` или JSON рядом), длина 8–15 с.
3. **2–3 прогона** на реальных строках плана. После каждого: правки человека → шаблон. Правки записывай в `шаблоны/<имя>/правки.md`, чтобы не повторять.
4. **Сохранение**: `шаблоны/<имя>/` = композиция + `README.md` (для каких строк плана, какие поля, сколько секунд, пример заполнения) + 1 готовый пример `пример.mp4`.
5. В `profile/paths.md` строка «Моушн-шаблоны: <имя> — для …». Рутина «медиа на 7 дней» берёт шаблон по этой строке.
Шаблон считается готовым, когда человек два прогона подряд не дал правок.
