# Carousel — 4 типа контента × 3 маршрута производства

Назначение: взять строку контент-плана и отдать готовую карусель — PNG по порядку, ссылка в таблице, статус «На утверждении».

## Где лежат профили
Профили лежат в папке `profile/` в корне проекта: `profile/business-dna.md`, `profile/audience.md`, `profile/hunt-ladder.md`, `profile/offer.md`, `profile/tone-of-voice.md`, `profile/design-system.md`, плюс паспорт `profile/foundation.html`. Google Drive — необязательное зеркало: коннектор подключён → продублируй туда; нет — работай с `profile/` и не останавливайся.

Перед работой прочитай `profile/audience.md`, `profile/offer.md`, `profile/tone-of-voice.md`, `profile/design-system.md`. Нет `design-system.md` → сначала `design-system-builder`.

## Словарь: тип контента и маршрут (общий с `content-plan`)

Колонка «Формат» контент-плана хранит и тип, и маршрут: **`Карусель · T2 · H`**. Разбирай оба поля. Если маршрута нет — бери маршрут по умолчанию из таблицы. Если нет типа — спроси одним вопросом.

| Тип | Название | Что на слайдах | Маршрут по умолчанию |
|---|---|---|---|
| **T1** | Текст-на-фоне | брендовый фон + типографика: списки, чек-листы, тезисы | **C** |
| **T2** | Фото-аватар | автор в сцене + текст, editorial-стиль | **H** |
| **T3** | Скриншоты | реальные скрины (таблица, Drive, результаты, переписка) + подписи | **C** |
| **T4** | Кейс-инфографика | цифры, до/после, сравнения, простые графики | **C** (сложная графика → **K**) |

| Маршрут | Чем делаем | Когда |
|---|---|---|
| **H** | Higgsfield `nano_banana_pro` + референс лица на каждом слайде | человек в кадре или сложная сцена |
| **C** | код: Python + Pillow, без браузера | текст, скрины, цифры поверх бренд-фона или реального фото |
| **K** | Canva через коннектор | нужна ручная доводка или работа с телефона |

За неделю — три карусели РАЗНЫХ типов (например T1 · C, T2 · H, T4 · C). План может переопределить маршрут (например `T1 · K`, если у человека Canva) — тогда делай так, как написано в плане.

## ГЛАВНОЕ ПРАВИЛО
**Higgsfield используется ТОЛЬКО когда на слайде ЧЕЛОВЕК (аватар/фото автора) или сложная сцена.** Генерить «текст на однотонном фоне» через Higgsfield ЗАПРЕЩЕНО — это делает код (C) или Canva (K).

## Маршрут H — Higgsfield (аватар в кадре)
- Модель **`nano_banana_pro`**, aspect_ratio 4:5, resolution 2k. **4 слайда** (обложка + 2 смысловых + финал с CTA).
- **НА КАЖДОМ слайде передавай reference sheet автора** в `medias: [{type:image, role:image, value:[media_id референса лица]}]` — иначе лицо плывёт от слайда к слайду. Лицо должно быть ОДИНАКОВЫМ на всех слайдах.
- Шаблон промпта слайда: «Use the person from the reference image, keep their exact face. Premium editorial Instagram carousel slide 4:5. <сцена из плана>. Brand palette <цвета из profile/design-system.md>, elegant typography, tasteful graphics, magazine quality. Integrate this EXACT Russian text, crisp and correctly spelled: «<текст слайда>». No watermark, no logos.»
- Стандарт сцен, текста и QA — `${CLAUDE_PLUGIN_ROOT}/skills/carousel/references/higgsfield-visual-standard.md`.
- Проверь текст и лицо; брак — 1 перегенер.

## Маршрут C — Код (Python + Pillow, БЕЗ браузера)
Рисуем холст напрямую. Браузер не нужен: ни Chrome, ни headless-рендер. Работает и на ноутбуке, и в облачной сессии.
1. Проверь окружение: `python3 -c "import PIL"` (Windows: `python -c "import PIL"`). Ошибка → `python3 -m pip install --user pillow`; ответ `externally-managed-environment` → `python3 -m venv ~/.reels-venv && ~/.reels-venv/bin/pip install pillow` и дальше запускай скрипты этим интерпретатором.
2. Фото автора — из папки `photos/` проекта (или её зеркала в Drive) по `photo-catalog.md`. Скрины для T3 — из колонки «Источник для скриншота».
3. Скрипт на Pillow: холст 1080×1350; фото вписать по cover, лицо не обрезать; градиент-скрим брендового цвета (на обложке — СВЕРХУ, чтобы не затемнять лицо); текст шрифтом бренда из `profile/design-system.md` (нет файла шрифта → скачай TTF с Google Fonts в `fonts/`); плашка CTA на финале; нумерация и ник.
4. Сохрани PNG по порядку в `output/carousel-[дата]-[тема]/` и залей в Drive (если подключён).
**Цепочка запасных:** нет Pillow и поставить не получается → собери эту карусель маршрутом **K (Canva)**. Есть локальный Chrome и хочется HTML-вёрстку → можно HTML→PNG через `chrome --headless --screenshot`, это необязательный путь. НИКОГДА не падай — всегда отдавай готовую карусель.

## Маршрут K — Canva
- Через Canva-коннектор: создай дизайн 1080×1350 в бренд-стиле (цвета/шрифты из `profile/design-system.md`).
- **Фото автора обязательно минимум на обложке и финале** (из папки `photos/` проекта).
- Экспортируй страницы в PNG и залей в Drive.

## Движок текста (ОБЯЗАТЕЛЬНО)
Перед текстом прочитай **`${CLAUDE_PLUGIN_ROOT}/skills/content-pipeline/references/copy-engine.md`** + `profile/tone-of-voice.md`. Без «не X, а Y», без канцелярита, без скобок-рода. Звучит генерично — перепиши.

## Структура текста
Обложка (7–8 слов, хук) → суть одной фразой → одна мысль на слайд → доказательство (цифра/кейс) → финал с CTA (сохрани/перешли или кодовое слово).

## Правила текста и фото
`${CLAUDE_PLUGIN_ROOT}/skills/carousel/references/text-and-photo-rules.md`: скрим под текстом, текст никогда не на лице, нейтральное «ты», выбор фото по каталогу.

## Запрещено
Плоская карусель «текст на однотонном фоне без дизайна»; белый текст на светлом; текст на лице; затемнённое лицо автора; женский род в скобках.

## Выдача
Готовые PNG → ссылка (Drive или локальная папка) в колонку «Ссылка на медиа», статус → «На утверждении». Одной строкой скажи, какой тип и маршрут использованы: `Карусель · T2 · H`.
