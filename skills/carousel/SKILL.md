# Carousel — 4 типа контента × 3 маршрута производства

Назначение: взять строку контент-плана и отдать готовую карусель — PNG по порядку, ссылка в таблице, статус «На утверждении».

## Где лежат профили
Папка `profile/` в корне проекта: `business-dna.md`, `audience.md`, `hunt-ladder.md`, `offer.md`, `funnels.md`, `tone-of-voice.md`, `design-system.md`, паспорт `foundation.html`. Drive — необязательное зеркало.

Перед работой прочитай `profile/audience.md`, `profile/offer.md`, `profile/tone-of-voice.md` (раздел «Мои запреты»), `profile/design-system.md`, `business-dna.md` → «Актуальный запуск» (даты и кодовые слова оттуда). Нет `design-system.md` → сначала `design-system-builder`.

## Словарь: тип и маршрут (общий с `content-plan`)
Колонка «Формат» хранит оба поля: **`Карусель · T2 · H`**. Нет маршрута — бери по умолчанию из таблицы. Нет типа — спроси одним вопросом.

| Тип | Название | Что на слайдах | Маршрут по умолчанию |
|---|---|---|---|
| **T1** | Текст-на-фоне | брендовый фон + типографика, карточка под текстом | **C** |
| **T2** | Фото-аватар | человек в сцене + текст, editorial | **H** |
| **T3** | Скриншоты | реальные скрины + подписи | **C** |
| **T4** | Кейс-инфографика | цифры, до/после, сравнения | **C** (сложная графика → **K**) |

## ГЛАВНОЕ ПРАВИЛО
**Higgsfield только когда человек в сцене** (T2). Текст на фоне, скрины, цифры — код (C) или Canva (K). **В каруселях C обложка и финал всегда с реальным фото человека из `photos/`**, средние слайды — текст на бренд-фоне.

## Маршрут H — Higgsfield (человек в сцене)
- Модель `nano_banana_pro`, 4:5, 2k, ≈2 кредита за слайд. 4–6 слайдов (обложка + смысловые + финал с CTA-плашкой).
- **Референс лица в `medias` на каждом слайде.** Нет Soul — сначала референс-лист за 2 кредита, потом слайды с ним (раздел в шаблоне).
- **Промпт слайда — только по `${CLAUDE_PLUGIN_ROOT}/skills/carousel/references/higgsfield-prompt-template.md`**: шаблон целиком на каждом слайде, один наряд, палитра из design-system, ONE full-bleed frame, текст один раз, «each line exactly once», без кавычек, без номеров слайдов и COVER.
- **Перед генерацией почисти промпт из таблицы** (раздел «Чистка» в шаблоне): убери «», «Слайд NN», «Slide N of M», COVER, CTA-метки; допиши строки про цельный кадр и «exactly once», если их нет. Текст — из колонки H дословно.
- Сцены и ловушки перевода — `${CLAUDE_PLUGIN_ROOT}/skills/carousel/references/higgsfield-visual-standard.md`.
- **QA после генерации:** текст побуквенно = H, нет кавычек и цифр, текст один раз, кадр цельный, лицо как на референсе, текст не на лице. Брак — 1 перегенерация.

## Маршрут C — код (Python + Pillow, без браузера)
Генератор `${CLAUDE_PLUGIN_ROOT}/templates/carousel-code/build_c.py` (скопируй `build_c.py` + `lab_common.py` в `tools/` проекта). JSON по типу — `examples/t1-text.json` и др.
1. Окружение: `python3 -c "import PIL"` (Windows `python`); ошибка → `pip install pillow`; `externally-managed-environment` → venv `~/.reels-venv`. Детектор лиц: `opencv-python-headless<5` + `fonts/haarcascade_frontalface_default.xml` — без него `build_c.py` выходит с кодом 6 на фото-слайдах, проверка «текст не на лице» обязательна.
2. **Обложка (`role: cover`) и финал (`role: cta`) — `photo:` реальное фото из `photos/`** по заметке в колонке H и `photo-catalog.md` (HEIC → `sips -s format jpeg`). Средние слайды — `big`/`small`/`number`, T3 — `screenshot`, T4 — `compare`. Бренд: `"brand": "profile/design-system.md"` (цвет карточки — поле «карточка» в дизайн-системе, иначе фон +5%).
3. `python3 tools/build_c.py spec.json --out output --name ДД.ММ-тема` → `slide-01..NN.png`, `00-contact.jpg`, `00-check.jpg`, `report.md`. Код 3 (текст на лице) → другое фото или `focus`; 4 (контраст) → другой фон; 6 (нет детектора) → поставь OpenCV<5 и каскад.
4. Посмотри `00-check.jpg`: лицо целиком, текст не на лице, ничего не вылезло.
**Запасные:** нет Pillow → маршрут K. Никогда не падай — отдавай готовую карусель.

## Маршрут K — Canva
Через Canva-коннектор: дизайн 1080×1350 в бренд-стиле из `profile/design-system.md`. Фото человека обязательно на обложке и финале (из `photos/`). Экспорт PNG.

## Движок текста (обязательно)
`${CLAUDE_PLUGIN_ROOT}/skills/content-pipeline/references/copy-engine.md` + `profile/tone-of-voice.md`. Без «не X, а Y», без канцелярита, без скобок-рода, без слов из «Мои запреты».

## Структура текста
Обложка (7–8 слов, хук) → суть одной фразой → одна мысль на слайд → доказательство (цифра/кейс) → финал с CTA (кодовое слово из `funnels.md`).

## Правила текста и фото
`${CLAUDE_PLUGIN_ROOT}/skills/carousel/references/text-and-photo-rules.md`: скрим под текстом, текст никогда не на лице, нейтральное «ты», фото по каталогу.

## Запрещено
Плоская карусель без дизайна; белый текст на светлом; текст на лице; затемнённое лицо; женский род в скобках; карусель C без реальных фото на обложке и финале; Higgsfield для слайдов без человека.
