# Режим «сравнение»: одна карусель четырьмя способами

Просят «сделай одну карусель четырьмя способами» или «сравни способы». Цель: человек видит одну и ту же карусель в C, H, K и D, выбирает свой микс и правит контент-план. Всё в **одном чате**, кроме Claude Design.

## 0. Что берём
Первая карусель из контент-плана (таблица или `контент-план/`) или строка, которую назвал человек. Текст слайдов один на все способы — дословно колонка H. Прочитай `profile/paths.md`: Higgsfield без пакета → способ H пропусти и скажи: «Higgsfield пропускаем, делаем три бесплатных способа».

Перед запуском одной строкой проверь: Python и Pillow есть (`python3 -c "import PIL"`, Windows `python`), Canva и Higgsfield подключены. Чего-то нет — поставь сам или скажи, какой коннектор подключить, и запускай остальное.

## 1. Запусти всё сразу
Порядок, чтобы долгое шло в фоне:
1. **H — Higgsfield.** Запусти генерацию всех слайдов батчем по маршруту H (кредиты назови до запуска: ≈2 за слайд). Не жди, иди дальше.
2. **K — Canva.** Запусти по `canva-route.md` (шаблона нет → сначала шаблон).
3. **D — Claude Design.** Собери папку `output/<дата>-<тема>/для-claude-design/` и промт по маршруту D. Сразу скажи человеку: «Пока остальное собирается, открой Claude Design: перетащи папку, вставь промт, в конце напиши «дай мне скачать в PNG». Готовые PNG положи в `D/`».
4. **C — код.** Собери по маршруту C, посмотри `00-check.jpg`.
5. Дождись H (`jobs_wait`), сделай QA, скачай в `H/`.

Всё складывай в одну папку:
```
output/<дата>-<тема>/
  C/  H/  K/  D/
  сравнение.md
```

## 2. Сравнение
Когда есть хотя бы три способа, собери `сравнение.md` и покажи в чат:

| | C код | D Claude Design | H Higgsfield | K Canva |
|---|---|---|---|---|
| Время на эту карусель | | | | |
| Цена | бесплатно | входит в Claude | <кредиты> | бесплатно |
| Текст без ошибок | | | | |
| Лицо и текст | | | | |
| Правки | словами в чате | в Claude Design | перегенерация | руками в Canva |
| Рутина | на компьютере | только вручную | облако | облако |

Заполни строки фактами этого прогона. Обложки четырёх способов собери рядом на одном листе `сравнение.jpg` (код, Pillow), чтобы было видно глазами.

## 3. Микс и план
Спроси один вопрос: «Какой способ для каких каруселей?» Подскажи вариант по умолчанию: ежедневные кодом (C, или X с банком фото, если есть Higgsfield), флагманская раз в неделю в Claude Design (D), ты в кадре — Higgsfield (H), Canva — если нравится править руками (K).

После ответа: запиши микс в `profile/paths.md` (раздел «Карусели») и поправь колонку «Формат» у каруселей в контент-плане (`Карусель · T1 · C` и т. д.). Покажи, сколько строк поменялось.
