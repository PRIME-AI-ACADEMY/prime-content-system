# Content Pipeline — конвейер производства контента

Назначение: превратить один исходник в набор готовых форматов под профиль пользователя, сохраняя в Google Drive/Таблицах.

## Движок текста (ОБЯЗАТЕЛЬНО для всех текстов)
Весь текст любого формата пишется по единому движку **`${CLAUDE_PLUGIN_ROOT}/skills/content-pipeline/references/copy-engine.md`** (анти-ИИ голос, банк хуков, вирусные паттерны, сценарные каркасы, CTA-движок на рост). Каждый форматный скилл тоже его читает.

## Где лежат профили
Профили лежат в папке `profile/` в корне проекта: `profile/business-dna.md`, `profile/audience.md`, `profile/hunt-ladder.md`, `profile/offer.md`, `profile/tone-of-voice.md`, `profile/design-system.md`, плюс паспорт `profile/foundation.html`. Google Drive — необязательное зеркало: коннектор подключён → продублируй туда; нет — работай с `profile/` и не останавливайся.

## Шаг 0 — профили
Прочитай `profile/audience.md`, `profile/offer.md`, `profile/tone-of-voice.md` (и `profile/design-system.md` для визуала). Нет — `foundation` или отдельный конструктор.

## Основной процесс
1. **Золотые куски:** извлеки минимум 5 (тип · суть · точная цитата · подходящие форматы).
2. **Генерация:** по каждому формату вызови свой скилл (reels/carousel/stories/short-post/long-post/article).
3. **Сохранение:** в таблицу, одна единица контента на строку. Файлы (слайды, видео, профили) в Drive — только через `${CLAUDE_PLUGIN_ROOT}/skills/content-pipeline/references/drive-bridge.md` (папка Drive для компьютера или мост Higgsfield → Drive; в K — ссылка на папку + CloudFront-ссылки файлов).
4. **Контроль качества:** прогони каждый текст через самопроверку движка (раздел 9): живой язык, конкретика, ноль канцелярита, CTA на рост.

## Критерии качества
- Преобразование материала, а не пересказ.
- Посты — короткие фразы (12–15 слов), reels — 8–10.
- Ноль канцеляризма и AI-штампов. Соответствие tone-of-voice.
- Каждая единица — с CTA на рост (сохрани/перешли/подпишись/слово в директ).

Режимы: полный · анализ-только · выборочный.
