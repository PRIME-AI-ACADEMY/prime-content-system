# Content Plan — оркестратор контент-плана

Назначение: цель → **рабочая таблица-календарь** → готовый контент. Минимум ручных утверждений: только (1) план и (2) образец из 2 постов. Дальше — автоматом.

## Где лежат профили
Папка `profile/` в корне проекта: `business-dna.md`, `audience.md`, `hunt-ladder.md`, `offer.md`, `funnels.md`, `tone-of-voice.md`, `design-system.md`, паспорт `foundation.html`. Drive — необязательное зеркало (мост: `${CLAUDE_PLUGIN_ROOT}/skills/content-pipeline/references/drive-bridge.md`).

## Шаг 0 — фундамент (обязательно)
Прочитай профили. Порядок чтения: **`business-dna.md` → раздел «Актуальный запуск» первым** (даты эфира, марафона, потока, кодовые слова, что не использовать — он главнее PDF и старых заметок), потом `funnels.md`, `audience.md`, `offer.md`, `hunt-ladder.md`, `tone-of-voice.md`, `design-system.md`. Нет ни одного — `foundation`. Нет `funnels.md` — запусти `funnels` (без него строки не разметить). Нет `design-system.md` — `design-system-builder`. Без `business-dna.md`, `audience.md` и `funnels.md` план не строй.

## Шаг 1 — три вопроса до плана (один AskUserQuestion)
1. **Горизонт**: 2 недели (по умолчанию) / неделя / месяц.
2. **Ритм в неделю**: по умолчанию **карусель каждый день (7) + 3 рилса**; варианты 3+3, 5+2, свой.
3. **События и воронки на период**: подтверди список из «Актуальный запуск» и `funnels.md` (эфир, марафон, старт потока, кодовые слова). Что изменилось — сразу допиши в `business-dna.md` → «Актуальный запуск».
Цель в числах — из `business-dna.md`; переспроси только если её нет.

## Шаг 1.5 — тип, маршрут, формат каждой строки
Словарь общий со скиллами `carousel` и `reels-montazh`. Колонка «Формат» хранит всё: **`Карусель · T2 · H`**, **`Reels · M`**, `Reels · M · говорящая голова`, `Reels · S`.

| Тип | Название | Что на слайдах | Маршрут по умолчанию |
|---|---|---|---|
| **T1** | Текст-на-фоне | брендовый фон + типографика, карточка под текстом | **C** |
| **T2** | Фото-аватар | человек в сцене + текст, editorial | **H** |
| **T3** | Скриншоты | реальные скрины + подписи | **C** |
| **T4** | Кейс-инфографика | цифры, до/после, сравнения | **C** (сложная графика → **K**) |

| Маршрут | Чем делаем | Когда |
|---|---|---|
| **H** | Higgsfield `nano_banana_pro` + референс лица на каждом слайде | **только когда человек в сцене** (T2) |
| **C** | код Python + Pillow (`templates/carousel-code/build_c.py`) | всё остальное; **обложка и финал всегда с реальным фото из `photos/`**, средние слайды — текст на бренд-фоне |
| **K** | Canva через коннектор | ручная доводка, телефон |

Reels — три формата, чередуй:
- **(а) `Reels · M · говорящая голова`** — монтаж записи человека: паузы, субтитры, вставки (скилл `reels-montazh`, трек Б);
- **(б) `Reels · M`** — клип из `clips/` + хук + CTA-плашка (трек А, `build_reel.py`);
- **(в) `Reels · S`** — аватар Higgsfield (стартовый кадр + Seedance ≤ 15 с, озвучка), для тех, у кого есть референс лица.
Нет клипов — (б) не планируй. Нет референса лица — (в) и T2·H не планируй.

За период чередуй типы каруселей (в неделе из 7 — минимум три разных типа, H не больше 2 в неделю: ≈24 кредита за неделю с двумя H). Сверяйся с трендами при выборе форматов: `${CLAUDE_PLUGIN_ROOT}/skills/content-plan/references/trends-2026-2027.pdf` (серии вместо разрозненных советов, бизнес-задача у каждой единицы, кейсы и метод, которые можно пересказать).

## Шаг 2 — стратегия периода
По `funnels.md` → раздел «Разметка строк»: баланс функций на неделю (охват 35–45% · прогрев 25–35% · продажа 15–20% · имидж ≤ 20%), ритм недель (проблема → метод → продажа → дожим), даты событий. Ступени по `hunt-ladder.md`. Каждая строка получает: **код воронки · функция · этап прогрева · CTA точной фразой из словаря · точка назначения · кодовое слово**. Лучше 5 публикаций в одну воронку, чем по одной в пять.

## Шаг 3 — ПРЕДВАРИТЕЛЬНЫЙ план в чат (утверждение № 1, не в таблицу)
Компактно, одна строка на пост:
```
ДД.ММ ЧЧ:ММ · Формат (Карусель · T1–T4 · H/C/K | Reels · M/S) · Тема · Хук · Воронка F1 · Функция · Ступень · CTA → точка назначения
```
Время по умолчанию: рилсы 12:00, карусели 18:00 (или из `business-dna.md`: «Reels HH:MM, карусели HH:MM»). Спроси: «Утверждаешь план?» Итерируй.

## Шаг 3.5 — ОБРАЗЕЦ из 2 постов (утверждение № 2, последнее)
Возьми 1 карусель + 1 рилс и распиши полностью, как пойдёт в таблицу (все колонки + промпт на каждый слайд). Спроси: «Стиль и качество ок? Так делаю остальные?». Перед текстом: `Read ${CLAUDE_PLUGIN_ROOT}/skills/content-pipeline/references/copy-engine.md` + `profile/tone-of-voice.md` (раздел «Мои запреты» обязателен).

## Шаг 4 — ВСЯ ТАБЛИЦА + промпт на каждый слайд
После одобрения образца распиши остальные строки в том же качестве и запиши всю таблицу одним batch. Лист «Контент-план», статус «План». **Схема 16 колонок A–P, без эмодзи:**
```
A Дата и время | B Формат | C Тема | D Хуки (3 варианта) | E Ступень Ханта | F CTA / ключ | G Higgsfield-промпт / Дизайн | H Текст слайдов / Voiceover | I Воронка | J Функция · Этап · Точка назначения | K Ссылка на медиа | L Статус | M Postiz | N Зашло / Не зашло | O Канал | P Ссылка на публикацию
```
- **A** — строго `ДД.ММ.ГГГГ ЧЧ:ММ` в часовом поясе человека (например `06.10.2026 18:00`). Рутины и сайт читают этот формат; Postiz получает UTC от `autopost`.
- **F** — CTA точной фразой из словаря `funnels.md` + кодовое слово.
- **I** — код воронки (`F1-СЛОВО`) или `имидж`.
- **J** — `Охват · Захват · бот → гайд` (функция · этап прогрева · точка назначения).
- **H** — текст каждого слайда `01 … 02 …` дословно; для рилса — сценарий ≤ 40 слов. **Здесь же, в конце, заметка о медиа:** какое фото из `photos/` на обложку и финал (по `photo-catalog.md`), какой клип из `clips/` для `Reels · M`, какой скрин для T3. Отдельных колонок «Медиа из банка» и «Источник скриншота» больше нет (старые таблицы с ними читать можно).
- **O** — `Instagram` / `Threads` / `Telegram`; пусто = Instagram. **P** заполняет `autopost`.

### Колонка G — промпт на каждый слайд
Для каруселей — не общий абзац, а промпт на каждый слайд, разделённый пустой строкой. Метка слайда для человека (`Слайд 01`) стоит **в колонке H**, в G её нет.
- **Маршрут H (T2):** каждый слайд — по шаблону `${CLAUDE_PLUGIN_ROOT}/skills/carousel/references/higgsfield-prompt-template.md`, целиком (референс лица, один наряд, палитра из design-system, ONE full-bleed frame, текст один раз, «each line exactly once», сцена на английском). **Запрещено в промпте:** кавычки «» вокруг русского текста, слова COVER / CTA, «slide N of M», номера слайдов, цифры в тексте, если они не часть смысла. Модель рисует всё это на картинке.
- **Маршрут C (T1/T3/T4):** описание для JSON `build_c.py`: роль слайда (cover / body / cta), `photo:` файл из `photos/` для обложки и финала, кикер, big/small текст с `*акцентом*`, `number`, `compare`, `screenshot`. Средние слайды — текст на бренд-фоне с карточкой.
- **Reels · M:** хук l1/l2, подпись, CTA, кикер; для говорящей головы — 2–4 тезиса для вставок. **Reels · S:** сцена стартового кадра на английском + движение камеры, без текста.
Каждый слайд самодостаточен: генератор берёт строку и делает без домысливания.

**Рабочая таблица, пополняется:** новые строки дописываются в тот же лист. Оформление: шапка в тёмном цвете фона бренда + светлый жирный текст + закреплена; тело — светлый цвет бренда, перенос по словам; Статус — выпадающий список (План · На утверждении · Утверждено · Запланировано · Опубликовано). Цвета из `profile/design-system.md`. Composio `FORMAT_CELL` требует все четыре отступа сразу; форматирование и сортировку делай последовательно, не параллельно с записью. Покажи ссылку.

## Шаг 5 — производство
`carousel` читает тип и маршрут из B, промпт из G, текст и заметку о медиа из H. `reels-montazh` — для `Reels · M`, `reels` — для `Reels · S`. Медиа → Drive по drive-bridge, в K ссылка на папку + CloudFront-ссылки файлов, статус «На утверждении». QA визуала с перегенерацией брака.

## Шаг 6 — сайт, утверждение, автопостинг
Сразу после таблицы — сайт контент-плана (`templates/content-dashboard/`, деплой через Vercel MCP `create_deployment`, CLI запасной). В таблице «Утверждено» / «Переделать». По «Утверждено» — `autopost` (Postiz, черновик первый раз). Рутины — `templates/routines/`.

## Автогенерация плана (рутина 01)
Каждое воскресенье — план на 2 недели вперёд, только на пустые дни (дни со строками пропускаются), карусель каждый день + 3 рилса, промпты H по шаблону, разметка воронками. Шаблон: `templates/routines/01-план-на-две-недели.md`.

## Контроль качества
- Только 2 утверждения: план в чат → образец → вся таблица.
- Прочитан «Актуальный запуск»: даты и кодовые слова в плане совпадают с ним?
- У каждой строки: воронка (I), функция · этап · точка назначения (J), CTA из словаря (F)? Имиджа без воронки ≤ 20%?
- У каждой карусели тип и маршрут, типы чередуются, H только с человеком в кадре?
- В G нет кавычек «», COVER, номеров слайдов; текст слайда один раз?
- В H есть заметка, какое фото/клип/скрин использовать?
- A в формате `ДД.ММ.ГГГГ ЧЧ:ММ`? 16 колонок без эмодзи?
- Текст без «не X, а Y», без скобок-рода, с учётом «Мои запреты» из tone-of-voice?
