# Content Plan — оркестратор контент-плана

Назначение: цель → **рабочая таблица-календарь** → готовый контент. Минимум ручных утверждений: только (1) план и (2) образец из 2 постов. Дальше — автоматом.

## Где лежат профили
Папка `profile/` в корне проекта: `business-dna.md`, `audience.md`, `hunt-ladder.md`, `offer.md`, `funnels.md`, `tone-of-voice.md`, `design-system.md`, паспорт `foundation.html`. Drive — необязательное зеркало (мост: `${CLAUDE_PLUGIN_ROOT}/skills/content-pipeline/references/drive-bridge.md`).

## Два режима (определи сам, не спрашивай)
| Режим | Как узнать | Что меняется |
|---|---|---|
| **Курс Prime AI** | в проекте есть `материалы/01–05` (Фундамент собран в курсе) | вопрос 1 по умолчанию «Предложи сам»; Google Таблица по желанию, без неё CSV + HTML; сайт плана только по просьбе |
| **С нуля** (офлайн-интенсив, `ПРОМТ-УЧАСТНИКА.md`) | `материалов/` нет, профили собраны `foundation` через интервью | вопрос 1 по умолчанию «Максимум: карусель каждый день + 3 рилса»; таблица в Google Sheets; сайт контент-плана сразу после таблицы (шаг 6) |
Остальное одинаково: воронки, путь производства, образец из 2 постов, разметка строк.

## Шаг 0 — фундамент (обязательно)
Прочитай профили. Порядок чтения: **`business-dna.md` → раздел «Актуальный запуск» первым** (даты эфира, марафона, потока, кодовые слова, что не использовать — он главнее PDF и старых заметок), потом `paths.md`, `funnels.md`, `audience.md`, `offer.md`, `hunt-ladder.md`, `tone-of-voice.md`, `design-system.md`. Нет ни одного — `foundation`. Нет `design-system.md` — `design-system-builder`. Без `business-dna.md` и `audience.md` план не строй.

**Нет `funnels.md` → собери воронки сам, не отправляя человека в другой скилл:** запусти `funnels` (в курсе Prime AI он берёт кодовые слова и лид-магниты из `материалы/05`), покажи карту одной строкой на воронку, спроси «что здесь неправда?» и после ответа иди дальше. Это часть того же запуска.

Есть `материалы/07-продуктовая-линейка.md` → часть строк плана ведёт на бесплатную консультацию по кодовому слову (рубрика «мои услуги», не больше 1–2 в неделю).

## Шаг 1 — путь и объём (один AskUserQuestion, 4 вопроса)
Есть `profile/paths.md` → вопросы 2–4 не задавай, покажи одной строкой, что там записано («Снимаешь себя, Higgsfield: бесплатные кредиты, сторис 3 раза в неделю. Меняем?» — менять только по ответу). Вопрос 1 задавай всегда.

1. **Сколько публикаций в неделю?** Первым вариантом с пометкой «рекомендую» ставь умолчание режима. Варианты: «Предложи сам» · «Лёгкий: 3 карусели + 2 рилса» · «Стандарт: 5 каруселей + 3 рилса» · «Максимум: карусель каждый день + 3–5 рилсов». «Предложи сам» → выбери по цели из `business-dna.md`, ответам 2–4 и времени (нет данных о времени — Стандарт) и объясни одной строкой: «Ставлю 5 каруселей и 3 рилса: …».
2. **Рилсы: как с видео?** «Снимаю себя на телефон» · «Есть свои видео, но в кадре не появляюсь» · «Ничего не снимаю, всё через Higgsfield» · «Микс».
3. **Higgsfield?** «Есть пакет» · «Только бесплатные кредиты» · «Нет».
4. **Сторис?** «Линия каждый день» · «2–3 линии в неделю» · «Пока без сторис».

Горизонт по умолчанию **2 недели** (14 дней с завтрашнего дня). Неделя или месяц — только если человек сам попросил.

Сохрани ответы в **`profile/paths.md`** (его читают `carousel`, `reels`, `reels-montazh`, `autopost`, рутины):
```markdown
# Путь производства · обновлено <дата>
- Публикаций в неделю: <N каруселей + M рилсов>
- Видео: <снимаю себя / свои видео без лица / только Higgsfield / микс>
- Higgsfield: <пакет / бесплатные кредиты / нет>
- Сторис: <каждый день / 2–3 линии в неделю / нет>
- Автопостинг: <не выбран> (выбирается в уроке про автопостинг: планировщик Meta / Metricool / Postiz)
```

## Шаг 1.5 — тип, маршрут, формат каждой строки
Словарь общий со скиллами `carousel` и `reels-montazh`. Колонка «Формат» хранит всё: **`Карусель · T2 · H`**, **`Reels · M · говорящая голова`**, `Reels · M`, `Reels · HF`, `Reels · S`, `Сторис · линия`.

| Тип | Название | Что на слайдах | Маршрут по умолчанию |
|---|---|---|---|
| **T1** | Текст-на-фоне | брендовый фон + типографика, карточка под текстом | **C** |
| **T2** | Фото-аватар | человек в сцене + текст, editorial | **H** или **X** |
| **T3** | Скриншоты | реальные скрины + подписи | **C** |
| **T4** | Кейс-инфографика | цифры, до/после, сравнения | **C** (флагманская → **D**) |

| Маршрут | Чем делаем | Когда |
|---|---|---|
| **C** | Claude Code: код Python + Pillow (`templates/carousel-code/build_c.py`) на дизайн-системе | основной, бесплатно; **обложка и финал с реальным фото из `photos/`**, средние слайды — текст на бренд-фоне |
| **D** | Claude Design по шаблону карусели из дизайн-системы, «дай мне скачать в PNG» | 1 флагманская в неделю: кейс, подборка, большая польза |
| **H** | Higgsfield `nano_banana_pro` + референс лица на каждом слайде | только с пакетом Higgsfield и **только когда человек в сцене**, не больше 2 в неделю |
| **X** | микс: обложка и финал — фото из банка Higgsfield `photos/банк/`, середина кодом как C | Higgsfield есть (пакет или кредиты уже потрачены на банк) |
| **K** | Canva через коннектор | только если человек сам попросил |

Higgsfield «нет» → только C и D. «Бесплатные кредиты» → C, D, X (если банк фото уже есть), H не планируй.

**Рилсы — формат по ответу 2:**

| Ответ | Форматы | Что в строке |
|---|---|---|
| Снимаю себя | `Reels · M · говорящая голова` (основа) + `Reels · M` | текст для суфлёра целиком |
| Свои видео без лица | `Reels · M`: клипы из `clips/` + текст-хук + CTA | какие клипы снять или взять |
| Только Higgsfield | `Reels · HF`: ролик из генераций (продукт в движении, место, сцена с героем по фото) + текст-хук | промпты сцен на английском, 2–4 клипа по 5 с |
| Микс | чередуй: хук из Higgsfield + голова + b-roll | что из чего |

`Reels · S` (аватар Higgsfield с озвучкой) — только при пакете Higgsfield и референсе лица. Нет клипов и ответ «свои видео» → в строке список, что доснять на телефон.

За период чередуй типы каруселей (в неделе минимум три разных типа). Сверяйся с трендами при выборе форматов: `${CLAUDE_PLUGIN_ROOT}/skills/content-plan/references/trends-2026-2027.pdf` (серии вместо разрозненных советов, бизнес-задача у каждой единицы, кейсы и метод, которые можно пересказать).

**Сторис** (если ответ 4 не «нет»): строка `Сторис · линия` на день линии. Тип линии из скилла `stories` (умная мысль, инфоповод, продающая) и связь с постом дня. Продающая линия — в неделю продажи по ритму воронки.

## Шаг 2 — стратегия периода
По `funnels.md` → раздел «Разметка строк»: баланс функций на неделю (охват 35–45% · прогрев 25–35% · продажа 15–20% · имидж ≤ 20%), ритм недель (проблема → метод → продажа → дожим), даты событий. Ступени по `hunt-ladder.md`. Каждая строка получает: **код воронки · функция · этап прогрева · CTA точной фразой из словаря · точка назначения · кодовое слово**. Лучше 5 публикаций в одну воронку, чем по одной в пять.

## Шаг 3 — ПРЕДВАРИТЕЛЬНЫЙ план в чат (утверждение № 1, не в таблицу)
Компактно, одна строка на пост:
```
ДД.ММ ЧЧ:ММ · Формат (Карусель · T1–T4 · C/D/H/X | Reels · M/HF/S | Сторис · линия) · Тема · Хук · Воронка F1 · Функция · Ступень · CTA → точка назначения
```
Над списком две строки: события периода из «Актуальный запуск» и воронки с кодовыми словами, под списком итог: сколько каруселей, рилсов, линий сторис и что нужно снять или сгенерировать за 2 недели.
Время по умолчанию: рилсы 12:00, карусели 18:00 (или из `business-dna.md`: «Reels HH:MM, карусели HH:MM»). Спроси: «Утверждаешь план?» Итерируй.

## Шаг 3.5 — ОБРАЗЕЦ из 2 постов (утверждение № 2, последнее)
Возьми 1 карусель + 1 рилс и распиши полностью, как пойдёт в таблицу (все колонки + промпт на каждый слайд). Спроси: «Стиль и качество ок? Так делаю остальные?». Перед текстом: `Read ${CLAUDE_PLUGIN_ROOT}/skills/content-pipeline/references/copy-engine.md` + `profile/tone-of-voice.md` (раздел «Мои запреты» обязателен).

## Шаг 4 — ВСЯ ТАБЛИЦА + промпт на каждый слайд
После одобрения образца распиши остальные строки в том же качестве и запиши всю таблицу одним batch. Лист «Контент-план», статус «План». **Схема 16 колонок A–P, без эмодзи:**

**Куда пишем таблицу.** Composio подключён (Google Sheets) → лист «Контент-план», как ниже. Не подключён → не останавливайся: сохрани `контент-план/контент-план-ДД.ММ.csv` (UTF-8 с BOM, разделитель `;`, те же 16 колонок; открывается в Excel, Numbers и импортом в Google Таблицы) и `контент-план/контент-план.html` (та же таблица страницей с цветами из `design-system.md`, строки по дням, открой в браузере). Скажи одной строкой: «Подключишь Google Таблицы — перенесу план туда одной командой».
```
A Дата и время | B Формат | C Тема | D Хуки (3 варианта, для рилс из банка `viral-hooks`) | E Ступень Ханта | F CTA / ключ | G Higgsfield-промпт / Дизайн | H Текст слайдов / Voiceover | I Воронка | J Функция · Этап · Точка назначения | K Ссылка на медиа | L Статус | M Postiz | N Зашло / Не зашло | O Канал | P Ссылка на публикацию
```
- **A** — строго `ДД.ММ.ГГГГ ЧЧ:ММ` в часовом поясе человека (например `06.10.2026 18:00`). Рутины и сайт читают этот формат; Postiz получает UTC от `autopost`.
- **F** — CTA точной фразой из словаря `funnels.md` + кодовое слово.
- **I** — код воронки (`F1-СЛОВО`) или `имидж`.
- **J** — `Охват · Захват · бот → гайд` (функция · этап прогрева · точка назначения).
- **H** — текст каждого слайда `01 … 02 …` дословно. Для рилса сценарий по блокам: `Хук (0–3 с)` · `Напряжение` · `Мясо` · `Доказательство` · `CTA` (40–60 секунд); у говорящей головы — текст для суфлёра целиком, живой речью, 90–130 слов; у `Reels · M` и `Reels · HF` — `Что снять / сгенерировать:` список кадров по 3–5 с. Для сторис — каждая сторис одной строкой `01 … 02 …` + интерактив (опрос, вопрос, стикер с кодовым словом). **Здесь же, в конце, заметка о медиа:** какое фото из `photos/` на обложку и финал (по `photo-catalog.md`), какой клип из `clips/` для `Reels · M`, какой скрин для T3. Отдельных колонок «Медиа из банка» и «Источник скриншота» больше нет (старые таблицы с ними читать можно).
- **O** — `Instagram` / `Threads` / `Telegram`; пусто = Instagram. **P** заполняет `autopost`.

### Колонка G — промпт на каждый слайд
Для каруселей — не общий абзац, а промпт на каждый слайд, разделённый пустой строкой. Метка слайда для человека (`Слайд 01`) стоит **в колонке H**, в G её нет.
- **Маршрут H (T2):** каждый слайд — по шаблону `${CLAUDE_PLUGIN_ROOT}/skills/carousel/references/higgsfield-prompt-template.md`, целиком (референс лица, один наряд, палитра из design-system, ONE full-bleed frame, текст один раз, «each line exactly once», сцена на английском). **Запрещено в промпте:** кавычки «» вокруг русского текста, слова COVER / CTA, «slide N of M», номера слайдов, цифры в тексте, если они не часть смысла. Модель рисует всё это на картинке.
- **Маршрут C (T1/T3/T4):** описание для JSON `build_c.py`: роль слайда (cover / body / cta), `photo:` файл из `photos/` для обложки и финала, кикер, big/small текст с `*акцентом*`, `number`, `compare`, `screenshot`. Средние слайды — текст на бренд-фоне с карточкой.
- **Reels · M:** хук l1/l2, подпись, CTA, кикер; для говорящей головы — 2–4 тезиса для вставок. **Reels · S:** сцена стартового кадра на английском + движение камеры, без текста.
Каждый слайд самодостаточен: генератор берёт строку и делает без домысливания.

**Рабочая таблица, пополняется:** новые строки дописываются в тот же лист. Оформление: шапка в тёмном цвете фона бренда + светлый жирный текст + закреплена; тело — светлый цвет бренда, перенос по словам; Статус — выпадающий список (План · На утверждении · Утверждено · Запланировано · Опубликовано). Цвета из `profile/design-system.md`. Composio `FORMAT_CELL` требует все четыре отступа сразу; форматирование и сортировку делай последовательно, не параллельно с записью. Покажи ссылку.

## Шаг 5 — производство
`carousel` читает тип и маршрут из B, промпт из G, текст и заметку о медиа из H. `reels-montazh` — для `Reels · M`, `reels` — для `Reels · S`. Медиа → Drive по drive-bridge, в K ссылка на папку + CloudFront-ссылки файлов, статус «На утверждении». QA визуала с перегенерацией брака.

## Шаг 6 — сайт, утверждение, автопостинг
Режим «с нуля» — сразу после таблицы, режим «курс» — только если человек попросил: сайт контент-плана (`templates/content-dashboard/`, деплой через Vercel MCP `create_deployment`, CLI запасной). В таблице «Утверждено» / «Переделать». По «Утверждено» — `autopost` (Postiz, черновик первый раз). Рутины — `templates/routines/`.

## Автогенерация плана (рутина 01)
Раз в 2 недели — план на 2 недели вперёд, только на пустые дни (дни со строками пропускаются), объём и форматы из `profile/paths.md`, промпты H по шаблону, разметка воронками. Шаблон: `templates/routines/01-план-на-две-недели.md`.

- В H есть заметка, какое фото/клип/скрин использовать?
