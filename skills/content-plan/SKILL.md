# Content Plan — оркестратор контент-плана

Назначение: цель → **рабочая таблица-календарь** → готовый контент. Минимум ручных утверждений: только (1) план и (2) образец из 2 постов. Дальше — автоматом.

## Где лежат профили
Профили лежат в папке `profile/` в корне проекта: `profile/business-dna.md`, `profile/audience.md`, `profile/hunt-ladder.md`, `profile/offer.md`, `profile/tone-of-voice.md`, `profile/design-system.md`, плюс паспорт `profile/foundation.html`. Google Drive — необязательное зеркало: коннектор подключён → продублируй туда; нет — работай с `profile/` и не останавливайся.

## Шаг 0 — фундамент (обязательно)
Прочитай профили из `profile/`. Нет ни одного — запусти `foundation` (один промт → четыре профиля + паспорт). Нет одного конкретного — запусти его конструктор: `business-dna`, `audience-builder`, `hunt-ladder`, `offer-builder`, `tone-of-voice-builder`, `design-system-builder`. Без `business-dna.md` и `audience.md` план не строй.

### Шаг 0.5 — дизайн-система ПЕРЕД планом (обязательно)
Если нет `profile/design-system.md` — сначала запусти `design-system-builder`. Спроси: любимые **цвета** (или 2–3 палитры) и **шрифты**. Только потом план.

## Шаг 1 — цель, период, МИКС форматов
Цель в числах, срок, ключевое событие.
- **Период гибкий: неделя / 2 недели / месяц** (спроси; по умолчанию неделя; месяц = 4 недельных блока).
- **Микс на неделю по умолчанию: 3 карусели + 3 reels** (6 постов; подстрой под ресурс). Карусели — РАЗНЫХ типов (НЕ однотипные).

## Шаг 1.5 — ТИП И МАРШРУТ КАЖДОЙ КАРУСЕЛИ (обязательно)

Словарь общий со скиллом `carousel`. Каждой карусели присвой **тип контента** и **маршрут производства** и запиши оба в колонку «Формат» в виде **`Карусель · T2 · H`**. Reels пишутся как `Reels`.

| Тип | Название | Что на слайдах | Маршрут по умолчанию |
|---|---|---|---|
| **T1** | Текст-на-фоне | брендовый фон + типографика: списки, чек-листы, тезисы | **C** |
| **T2** | Фото-аватар | автор в сцене + текст, editorial-стиль | **H** |
| **T3** | Скриншоты | реальные скрины (таблица, Drive, результаты, переписка) + подписи | **C** |
| **T4** | Кейс-инфографика | цифры, до/после, сравнения, простые графики | **C** (сложная графика → **K**) |

| Маршрут | Чем делаем | Когда |
|---|---|---|
| **H** | Higgsfield `nano_banana_pro` + референс лица на каждом слайде | человек в кадре или сложная сцена |
| **C** | код: Python + Pillow, без браузера | текст, скрины, цифры поверх бренд-фона или реального фото |
| **K** | Canva через коннектор | нужна ручная доводка или работа с телефона |

За период **чередуй типы** (не 3 одинаковые). Маршрут по умолчанию бери из таблицы; переопределяй, только если у человека есть причина (например Canva вместо кода — `T1 · K`). Через месяц по колонке «Зашло / Не зашло» смотри, какой тип и тема заходят, и смещай план в их сторону.

## Шаг 2 — стратегия периода
По лестнице Ханта (`profile/hunt-ladder.md`): баланс прогрев (1–3) / продажа (4–5) / вовлечение, привязка к событию.

## Шаг 3 — ПРЕДВАРИТЕЛЬНЫЙ план В ЧАТ (утверждение № 1 — НЕ в таблицу)
Покажи план прямо в чате — компактно, с типом и маршрутом каждой карусели:
```
День/Дата · Формат (Карусель · T1–T4 · H/C/K  или  Reels) · Тема · Идея/угол · Хук · Ступень Ханта · CTA
```
Без детальных промптов, без записи в таблицу. Каждая тема — сильная, конкретная. Спроси: «Утверждаешь план?» Итерируй до одобрения.

## Шаг 3.5 — ОБРАЗЕЦ из 2 постов (утверждение № 2, последнее)
Возьми из плана **2 поста РАЗНЫХ форматов (напр. 1 карусель + 1 reels)** и распиши ПОЛНОСТЬЮ, детально — как пойдёт в таблицу (все колонки + **промпт на каждый слайд**, см. Шаг 4). Покажи в чате. Спроси: **«Стиль и качество ок? Так делаю остальные?»** Это ЕДИНСТВЕННЫЙ контроль качества промптов.
Перед любым текстом: `Read ${CLAUDE_PLUGIN_ROOT}/skills/content-pipeline/references/copy-engine.md` + аудит (нет «не X, а Y», нет скобок-рода).

## Шаг 4 — ВСЯ ТАБЛИЦА + ПРОМПТ НА КАЖДЫЙ СЛАЙД (обязательно)
После одобрения образца — распиши ОСТАЛЬНЫЕ строки в ТОМ ЖЕ качестве и СРАЗУ запиши ВСЮ таблицу. Не спрашивай утверждение по каждому.
Лист «Контент-план», статус = «План». **ФИКСИРОВАННАЯ схема 16 колонок A–P, БЕЗ эмодзи:**
```
Дата | Формат | Тема | Хуки (3 варианта) | Ступень Ханта | CTA / ключ | Higgsfield-промпт / Дизайн | Voiceover / Текст слайдов | Медиа (из банка) | Источник для скриншота | Ссылка на медиа (Drive) | Статус | Postiz (запланировано) | Зашло / Не зашло | Канал | Ссылка на публикацию
```
- **O «Канал»** — `Instagram` / `Threads` / `Telegram`; пусто = Instagram. По ней сайт раскладывает строки по вкладкам.
- **P «Ссылка на публикацию»** — заполняет `autopost` после выхода поста; на сайте становится кнопкой «Открыть пост».
- Дата в колонке A — `2026-09-17` или `17.09.2026` (с годом), чтобы сайт и рутины читали её однозначно.

### Колонка «Higgsfield-промпт / Дизайн» — ПРОМПТ НА КАЖДЫЙ СЛАЙД (критично)
Для каруселей эта колонка — **НЕ общий абзац, а ПРОНУМЕРОВАННЫЙ промпт на КАЖДЫЙ слайд:**
```
Слайд 01 (обложка): <маршрут H/C/K> · <тип T1–T4> · сцена/фон · где аватар (референс лица) · какое фото из банка · палитра · текст-на-слайде reads-exactly · графика
Слайд 02: …
…
Слайд NN (финал): … + плашка с кодовым словом
```
- **T2** (фото-аватар, маршрут H): на обложке/финале — аватар в сцене (`nano_banana_pro` + medias референс лица), средние — рич-дизайн с графикой.
- **T1** (текст, маршрут C): код-вёрстка на Python + Pillow по `profile/design-system.md`, без браузера.
- **T3** (скрины, маршрут C): что за скрин, откуда взять и какая подпись.
- **T4** (инфографика, маршрут C или K): что за цифра/график/сравнение.
Каждый слайд САМОДОСТАТОЧЕН: агент-генератор берёт строку и делает без домысливания. Для Reels — покадровый сценарий + промпт на каждый кадр.

**РАБОЧАЯ таблица, пополняется:** неделя → +неделя → месяц НА ТОМ ЖЕ листе.
Оформление — **никогда чёрный текст на белом:** шапка тёмный фирменный фон + белый жирный текст + закреплена + без эмодзи; тело бренд-беж + перенос по словам; ширина колонок без обрезки; Статус — выпадающий список (План · На утверждении · Утверждено · Запланировано · Опубликовано). Цвета — из `profile/design-system.md` (по умолчанию pine `#00311e`, cream `#fef7e5`, gold `#e8b96a`). Покажи ссылку.

## Шаг 5 — производство (по утверждению)
Для выбранных строк вызывай `content-pipeline`/формат-скилл по готовым послайдным промптам. `carousel` читает из колонки «Формат» тип и маршрут (`Карусель · T2 · H`). Медиа → Drive, ссылка → в строку, статус → «На утверждении». QA визуала (кириллица/лицо/сцена) с перегенерацией брака.

## Шаг 6 — цикл утверждения и автопостинг
В таблице «Утверждено» / «Переделать». По «Утверждено» — `autopost` (Postiz по умолчанию; статус → «Запланировано» → после даты «Опубликовано»). См. рутины `content-routine`.

## Автогенерация плана (рутина)
План может генерироваться сам: рутина «воскресенье → сгенерируй план на следующую неделю (или 2 недели / месяц) по этому скиллу, 3 карусели + 3 reels разных типов, статус План».

## Контроль качества
- Порядок: план в чат → образец 2 постов → (одобрение) → вся таблица автоматом. Только 2 утверждения.
- У каждой карусели в «Формат» есть тип T1–T4 и маршрут H/C/K, типы чередуются?
- У каждого слайда/кадра — свой детальный промпт (сцена/аватар/фото/стиль)?
- Микс 3 карусели + 3 reels на неделю?
- 14 колонок без эмодзи, статус-дропдаун, шапка закреплена, текст не обрезан?
- Текст без «не X, а Y» и скобок-рода?
