# Режим «видео в Higgsfield»: аватар, референс-лист, модели, режиссёр

Задача: рилс без съёмки. Человек или продукт в кадре держится одинаковым во всех сценах, видео генерируется по строке плана, текст ставит монтаж (урок 13), в генерации текста нет. Только с пакетом Higgsfield.

## Правила для всех шагов
- Перед каждой генерацией назови цену в кредитах (`get_cost: true`) и жди «да». Сначала 1 тест, потом остальное.
- В видео и стартовых кадрах **нет текста, букв, логотипов**. Текст, субтитры и CTA ставит `reels-montazh`.
- 9:16, длина клипа 4–6 секунд: из коротких клипов монтаж собирает рилс.
- Готовые клипы скачивай в `clips/` с именами `ДД.ММ-тема-hf-01.mp4` и дописывай `clips/каталог.md` (как в режиме «исходники»).

## Шаг 1. Аватар: какой путь
Спроси одной строкой, если непонятно из `profile/paths.md`: «В кадре ты, вымышленный персонаж или продукт?»

| Путь | Что это | Когда |
|---|---|---|
| **Элемент** (`manage_reference_elements`, create) | твоё лицо по 1 чёткому фото или по референс-листу, готово сразу | основной путь для видео: работает в Seedance 2.0, Kling 3.0 (нужен стартовый кадр), Cinema Studio, Nano Banana Pro |
| **Soul** (`show_characters`, train) | обученная модель лица, 5–20 фото, ~10 минут | только фото в моделях Soul. Для видео не нужен |
| **AI-персонаж** (`build_ai_influencer`) | вымышленный герой бренда, лист персонажа | человек не хочет показывать лицо: маскот, ведущий, герой сторис |
| **Продукт** (элемент, category `prop`) | товар по 1–3 фото | бренд, магазин, мастер: продукт в сценах |

Элемент назови понятно (`me-anna`, `product-candle`). id запиши в `profile/paths.md` строкой «Higgsfield-элемент: …».

## Шаг 2. Референс-лист
Если `photos/reference-sheet.png` ещё нет: сделай по `${CLAUDE_PLUGIN_ROOT}/skills/carousel/references/reference-sheet-prompt.md` (фото анфас `photos/reference-front.jpg`, `nano_banana_pro`, 3:2, шесть ракурсов). Проверь по чек-листу оттуда. Лист — лучший источник для элемента: создай элемент из листа, а не из одного фото. Для AI-персонажа лист даёт сам `build_ai_influencer`.

## Шаг 3. Модели на одном примере
Возьми одну строку `Reels · HF` или `Reels · S` из плана и сделай одну и ту же сцену 4–5 секунд разными моделями, чтобы человек увидел разницу. Цену каждой назови заранее.

| Модель | id | Сильная сторона | Ориентир цены |
|---|---|---|---|
| Seedance 2.0 | `seedance_2_0` | держит лицо по элементу, живая мимика, свой звук | fast 720p 5 с ≈ 12–13 кредитов |
| Kling 3.0 | `kling3_0` | движение и физика, мультикадр; лицо из стартового кадра | std 5 с без звука ≈ 7–8 кредитов |
| Genjutsu, перенос движения | `hf_mult_motion_control` | движение, жест или танец из ролика-образца переходит на твоего аватара | цену назови по `get_cost` |
| Genjutsu, замена | `hf_mult_replace_object` | в готовом ролике меняется предмет, одежда или персонаж на твой | по `get_cost` |
| Genjutsu Styles | `get_presets` source `genjutsu`, category `genjutsu-styles` | твоё видео перерисовывается в стиль: мультяшный 2D, игрушечный 3D, вязаный мир, движение то же | по цене пресета |
| Seedance 2.5, Cinema Studio | `seedance_2_5`, `cinematic_studio_video_4_0` | длинные и киношные сцены до 30 с | дорого: 10 с ≈ 70 кредитов |

Стартовый кадр для Kling: `nano_banana_pro` 9:16 с элементом в промте (`<<<id>>>`), без текста. Образец движения для Genjutsu: ролик-выброс из `исследование/вирусные-рилс/` (урок 11) или свой. Движение берём как механику, чужое лицо не используем.

Итог в чат таблицей: модель · кредиты · что получилось · где лицо поплыло. Спроси, какая модель основная. Запиши в `profile/paths.md` строкой «Видео Higgsfield: основная модель …».

## Шаг 4. Агент-режиссёр
По строке плана (тема, хук, сценарий из H):
1. **Раскадровка** таблицей: 3–5 кадров по 3–5 секунд. Кадр · что в кадре · движение камеры · какая модель · длина. Первый кадр отвечает за хук. В чат, жди «да».
2. **Промт на каждый кадр** на английском, по структуре: SUBJECT (кто, `<<<id>>>` элемента) · LOCATION · ACTION с таймкодами · CAMERA (план, движение, оптика) · STYLE (свет и цвет из `profile/design-system.md`) · CONSTRAINTS (`9:16, no text, no letters, no logos, same face as reference, natural hands`). Все кадры в одном стиле: одинаковые строки STYLE и CONSTRAINTS.
3. **Стартовые кадры** в `nano_banana_pro`, если модель кадра их требует. Сначала первый кадр как тест.
4. **Цена всей раскадровки** одной суммой, «да», генерация пачкой (`generate_video_batch`).
5. Проверка: лицо то же, руки целые, нет текста и артефактов. Брак — перегенерация только этого кадра.
6. Клипы в `clips/`, каталог, в плане в H: «клипы готовы: …, следующий шаг монтаж».

## Проверка
Цена названа до каждой генерации? В видео нет текста? Лицо одно во всех кадрах? Клипы лежат в `clips/` и в каталоге?
