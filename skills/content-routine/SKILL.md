# Content Routine — ежедневный автопилот

Две задачи по расписанию, которые превращают контент-план в автономный конвейер.

## Где лежат профили
Профили лежат в папке `profile/` в корне проекта: `profile/business-dna.md`, `profile/audience.md`, `profile/hunt-ladder.md`, `profile/offer.md`, `profile/tone-of-voice.md`, `profile/design-system.md`, плюс паспорт `profile/foundation.html`. Google Drive — необязательное зеркало: коннектор подключён → продублируй туда; нет — работай с `profile/` и не останавливайся. Облачная рутина без доступа к папке проекта читает зеркало в Drive — значит, для автопилота зеркало обязательно.

## Утро (напр. 08:00) — генерация на N дней вперёд
1. Прочитай контент-план. Отбери строки на ближайшие N дней без медиа (ссылка пустая).
2. Для каждой сгенерируй контент по её формату: колонка «Формат» = `Карусель · T1–T4 · H/C/K` или `Reels` — используй скиллы `carousel`, `reels` и т.д., `profile/design-system.md` и банк фото.
3. Залей в новую папку Google Drive → впиши ссылку, статус = «Запланировано».
4. Ничего не публикуй.

## Ночь (00:00) — автопостинг + проверка
1. Прочитай план. Если все строки со ссылкой имеют статус «Запланировано»/«Опубликовано» — всё ок (А НЕ ошибка).
2. Для строк «Запланировано» с медиа → скилл `autopost` (Postiz).
3. Отметь «Опубликовано».

## Как поставить
Cron-задачи (локально `~/.claude/scheduled-tasks/` или облачная рутина). Промпт каждой задачи — самодостаточный: `[id Google-таблицы контент-плана]`, `[ссылка на Drive-папку с профилями и фото]`, коннекторы, правила. Человеческий контроль = опционально статус «Утверждено».

Коннекторы: Higgsfield, Composio (Drive/Sheets), Postiz.
