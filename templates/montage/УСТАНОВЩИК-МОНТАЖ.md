## Шаг 5. КРИТИЧНО: шрифт с кириллицей

Системный Montserrat — **без кириллицы**: нет `ы ъ э ё`, нет `→`. Текст выйдет квадратами, и это видно только на готовом рендере.

1. Скачай полную версию с Google Fonts (команда одинаковая на Mac и Windows в Git Bash; в PowerShell пиши `curl.exe`):
   ```
   mkdir -p brand/assets/fonts
   curl -sL -o brand/assets/fonts/Montserrat-VF.ttf "https://github.com/google/fonts/raw/main/ofl/montserrat/Montserrat%5Bwght%5D.ttf"
   ```
2. Проверь размер: файл должен быть **больше 100 КБ** (обычно ~745 КБ). Меньше — это страница ошибки, перекачай.
3. Скопируй запасную копию в общее место, чтобы любой скрипт находил шрифт из любой папки:
   `mkdir -p ~/.reels-fonts && cp brand/assets/fonts/Montserrat-VF.ttf ~/.reels-fonts/`
   Туда же — каскад лиц (0.9 МБ), чтобы детектор работал даже с OpenCV 5 и без интернета:
   `curl -sL -o ~/.reels-fonts/haarcascade_frontalface_default.xml "https://raw.githubusercontent.com/opencv/opencv/4.x/data/haarcascades/haarcascade_frontalface_default.xml"`
4. **Проверь глифы кодом**, не глазами. Создай файл `tools/check_font.py`:
   ```python
   from PIL import ImageFont, Image, ImageDraw
   f = ImageFont.truetype("brand/assets/fonts/Montserrat-VF.ttf", 60)
   def bmp(c):
       im = Image.new("L", (120, 120), 0)
       ImageDraw.Draw(im).text((5, 5), c, font=f, fill=255)
       return im.tobytes()
   missing = [c for c in "ыъэёЫЪЭЁ→«»—іїєґ" if bmp(c) == bmp("\uf8ff")]
   f.set_variation_by_axes([800])  # вариативный вес — должно пройти без ошибки
   print("отсутствуют:", missing or "нет — всё ок")
   ```
   Запусти `$PY tools/check_font.py`. Должно напечатать «нет — всё ок». Иначе — перекачай шрифт.

# Правила монтажа Reels

## Формат
- Вертикаль 1080×1920, 30fps, .mp4, вывод в reels/out/. Бренд — строго из brand/design-system.md. Факты об окружении (питон, кодек, ник, язык) — из .studio-env: читать первым делом.

## ДВА ТРЕКА — главное решение
**ТРЕК А (ffmpeg + Python/Pillow)** — хук-рилсы, пачки, обрезка 5–7 сек. Pillow рисует прозрачный PNG-оверлей 1080×1920, ffmpeg накладывает фильтром overlay и рендерит. Whisper и HyperFrames НЕ нужны.
**ТРЕК Б (HyperFrames)** — говорящая голова, субтитры синхронно с речью, моушн-вставки. Нужен установленный проект HyperFrames (папка reels-hf/) и транскрипт.
Вопрос для выбора: **нужна анимация и синхрон с речью?** Да → Б. Нет → А. На воркшопе — А.

## Подготовка видео (оба трека) — не пропускать
- Файлы искать без учёта регистра: .mp4 .MP4 .mov .MOV .m4v. Пути с пробелами и кириллицей — в кавычках. Windows: прямые слэши.
- Не все видео вертикальные. `scale=1080:1920` растягивает и сплющивает лицо. Всегда: `scale=1080:1920:force_original_aspect_ratio=increase,crop=1080:1920`.
- Звуковой дорожки может не быть. Проверять: `ffprobe -v error -select_streams a -show_entries stream=index -of csv=p=0 файл`. Пусто → добавить вход `-f lavfi -t <D> -i anullsrc=r=44100:cl=stereo`, иначе фильтр падает с «Stream specifier ':a' matches no streams».
- Видео короче цели — брать полную длину, не тянуть. Видео больше/меньше, чем хуков — взять минимум и сказать число.
- 4K-исходник — сначала даунскейл до 1080×1920, потом всё остальное.

## Текст на видео — три железных правила (трек А)
1. **Градиент сверху — ВСЕГДА.** Тёмный (цвет фона бренда) → прозрачный, высота ~800px, непрозрачность у края ~95%, под верхним текстом. Плюс градиент снизу ~540px под плашку. Без градиента текст на светлом фоне не читается.
2. **Хук высоко и мелко, НЕ на лице.** Блок начинается y≈120: кикер (акцент, 600, ~42px) → строка 1 (текст, 800, до 120px) → строка 2 (акцент, 800, до 80px) → подпись (600, ~40px). Кегль авто-уменьшать, пока строка не влезет в ширину 1080−2×80. Блок заканчивается не ниже head_top=500; ниже — укоротить строки. Под текстом — мягкая тёмная тень (смещения ±3px). Ключевое слово — подчёркивание акцентным цветом, не другим цветом текста.
3. **CTA внутри плашки.** Плашка акцентного цвета со скруглением 30px, y 1560–1720, x 72–1008. Текст CTA (тёмный цвет фона, 700) измерять и уменьшать, пока не влезет с полями 40px. Никогда не вылезает за плашку. @ник (600, ~38px, текст с прозрачностью 0.9) по центру под плашкой.
- Хук появляется на 0.25с, держится ~60% ролика, уходит плавно (fade). CTA-плашка — последние 2 сек или весь ролик, если ролик ≤6 сек.
- Прогресс-бар акцентным цветом снизу — весь ролик (опционально).

## ЖЁСТКОЕ правило: текст НЕ на лице — гарантирует скрипт, не глаза
- Текст на видео накладывать ТОЛЬКО через `tools/build_reel.py` (питон из .studio-env):
  `$PY tools/build_reel.py --src "<клип>" --out "reels/out/<имя>.mp4" --kicker "..." --l1 "..." --l2 "..." --sub "..." --cta "..." --handle "<ник из .studio-env>"`.
  Скрипт сам: берёт кадры исходника каждые 0.5с → находит лица (OpenCV) → строит запретную зону (все лица + 40px) → ставит верхний блок над ней (уменьшает шрифт → убирает sub → переносит блок вниз над плашкой) → рендерит → достаёт 3 кадра готового ролика и проверяет пересечения → пишет контрольный лист `<имя>.check.jpg` ВСЕГДА.
- Коды выхода: 0 ок · 2 нет шрифта · 3 `[FAIL] текст на лице` → укоротить строки / другой клип, перерендерить · 4 «лицо занимает весь кадр» → другой клип. Не игнорировать, не «допиливать руками».
- Скрипт рисует в сетке 720×1280 (Instagram отдаёт то же качество). Нужна пачка в 1080×1920 — сначала собрать 720, показать листы, потом при желании перерендерить.
- Нет `tools/build_reel.py` или нет cv2 — работать по правилам выше вручную: контрольный кадр из КАЖДОГО видео (~25% длительности) → контактный лист → зоны лиц → текст в пустую зону → после рендера кадры на 2 точках → перерендер проблемных. Верх 220px и низ 200px — интерфейс Instagram. Боковые поля 80px.
- В любом режиме: все `*.check.jpg` склеить в один контактный лист и показать мне — я смотрю глазами.

## Субтитры и вставки (трек Б, говорящая голова)
- Не резать речь автонарезкой по тишине: срезаются тихие хвосты слов. Резать только паузы длиннее 1 сек с запасом 0.2 сек по краям и пустой хвост/начало. Перед каждым срезом — кадр: убедиться, что это пауза, а не тихая речь.
- Сначала собрать нарезанное видео, ПОТОМ транскрибировать его (whisper, модель medium для ru/uk, язык форсировать флагом). Тайминги тогда точные без пересчёта.
- Субтитры фразами (2–3 слова), не по одному слову — whisper-тайминги плавают ±0.3с, фразы это прощают. Сдвиг +0.15с.
- Позиция: НАД ГОЛОВОЙ, top ≈ 210px, на градиенте сверху. Низ — слепая зона Instagram. Шрифт Montserrat 900 ≈ 58px, цвет текста бренда, ключевые слова — подчёркивание акцентом.
- Полноэкранные вставки (2–4 на ролик, по 2–3 сек, на ключевых фразах): тёмная бренд-панель, схема/карточка/сетка иконок. Начинать невидимыми (gsap.fromTo opacity 0→1). Субтитры идут поверх вставок непрерывно (z-index выше).
- Акцент-чипы — на торс (bottom ≈ 380px), не на голову.
- Каждый `<audio>` ОБЯЗАН иметь id, class="clip", data-start/duration/track-index, src — иначе рендер без звука.
- Порядок: правка → `npm run check` → `snapshot` кадров на 5 таймкодах → проверить «не на лице» → `npm run render`.

## Рендер
- Кодек — из .studio-env: Mac `-c:v h264_videotoolbox -b:v 9M`; Windows/без аппаратного `-c:v libx264 -preset veryfast -crf 21`. Всегда `-pix_fmt yuv420p` и `-movflags +faststart`, иначе Instagram не откроет.
- Аудио `-c:a aac -b:a 128k`. Пачку рендерить параллельно: Mac 4–6 процессов, Windows/слабый ноутбук 2–3. Длинные — первыми.
- Не запускать ffmpeg через `nohup ... &` внутри фоновой задачи — процесс отвяжется. Либо ждать в той же команде, либо отдельным ожиданием по PID.
- После рендера `ffprobe`: есть видео, есть аудио, длительность не нулевая.

## Windows-ветка
- `python` вместо `python3`; питон из venv — `~/.reels-venv/Scripts/python.exe`. Пути в кавычках, прямые слэши.
- Нет `h264_videotoolbox`, нет `sips`, нет `say`. Нет `whisper-cli` — для субтитров использовать `npx hyperframes transcribe` или пропустить трек Б.

## Шаг 8. ТРЕК Б — HyperFrames (ОПЦИОНАЛЬНО; дома, не на воркшоп-wi-fi)

Спроси меня: «Ставим HyperFrames сейчас или дома?» На воркшопе ответ — **дома**: первый рендер качает собственный Chrome (~150 МБ), пачка участников кладёт wi-fi. Для простых хук-рилсов он не нужен.

Если «сейчас/дома»:
1. `npx hyperframes@latest skills update` — ставит скиллы движка в проект.
2. `npx hyperframes init reels-hf --resolution portrait --example blank --non-interactive` — создаёт проект в папке `reels-hf/`. Без `--example blank` команда с `--non-interactive` падает — аргумент обязательный.
3. Скажи мне **начать новый чат** в приложении — иначе новые скиллы не подхватятся.
4. **Windows:** Chrome скачивается при первом `npm run render`, Defender может проверять его 1–2 минуты — это не зависание.
