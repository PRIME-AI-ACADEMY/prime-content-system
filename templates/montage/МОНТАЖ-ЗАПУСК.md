# ПРОМТ А — пачка простых рилсов с хуками (воркшоп)

## Что получишь через 10 минут
- В `reels/out/` — по одному `.mp4` на каждое видео из `reels/in/` (5 клипов → 5 роликов), 720×1280, со звуком, готовые к загрузке в Instagram.
- Рядом с каждым — `<имя>.check.jpg`: три кадра ролика, лицо обведено красным, текст — золотым, подпись «ок». Это доказательство, что текст не на лице.
- Один общий контактный лист всех роликов и таблица «файл → хук → где стоит текст».
- Время: ~1 минута на ролик на Mac, 2–3 на Windows. Пока рендерится — ничего не трогай.

## Промт (заполни поля в [скобках], вставь целиком)

Собери мне пачку простых Reels с хуками из `HOOKS.md` (или из прикреплённого документа), по скиллу reels-montazh и моему бренду (`brand/design-system.md`). Факты об окружении бери из `.studio-env` — питон, кодек, ник, язык, кодовое слово. Прочитай эти три файла первыми.

**Мои поля:**
- Ниша / тема: **[напр. «нейросети для экспертов»]**
- Видео лежат в: **`reels/in/`** *(если видео нет — напиши «без видео», собери хуки на бренд-фоне)*
- Сколько роликов: **сколько видео — столько роликов** (на воркшопе 5)
- Длина каждого: **6 секунд**, обрезать от начала; видео короче — брать целиком
- Текст на ролике: кикер (сегмент/дата) + хук в 1–2 строки + подпись + CTA-плашка с кодовым словом + @ник

**Каким способом:** ТРЕК А — **`tools/build_reel.py`** (Python/Pillow рисует, ffmpeg рендерит, OpenCV следит за лицом). HyperFrames, whisper, субтитры — НЕ нужны.

**Перед монтажом проверь и скажи мне числа:**
1. Папка `reels/in/` существует, видео в ней есть. Ищи без учёта регистра: `.mp4 .MP4 .mov .MOV .m4v`. Пути в кавычках; Windows — прямые слэши.
2. Сколько видео и сколько хуков в документе — посчитай фактически. Разное количество → бери меньшее и скажи, сколько роликов выйдет.
3. Для каждого видео: разрешение, длительность, есть ли звук. Горизонтальные — НЕ растягивать (скрипт сам делает cover-кроп). Без звука — рендер без звука, предупреди меня.
4. `$PY tools/build_reel.py --help` работает и `import cv2` есть. Нет cv2 → скажи мне и работай в режиме без детекции по правилам скилла (контрольные кадры руками).

**Что сделать:**
1. Хуки бери из моего документа. Сегмент, лид-магнит и кодовое слово — оттуда, не выдумывай.
2. Сначала обрежь каждое видео до 6 сек (`ffmpeg -t 6 -c copy` в `reels/tmp/`), потом накладывай текст.
3. Для каждого ролика запусти `tools/build_reel.py` с полями: `--kicker` (сегмент или дата), `--l1` (хук, самое важное, ≤4 слов), `--l2` (продолжение хука, акцентный цвет), `--sub` (одна фраза-пояснение, можно пусто), `--cta "Пиши «КОДОВОЕ СЛОВО» — пришлю [лид-магнит]"`, `--handle` из .studio-env, `--out reels/out/<номер>-<2-3 слова хука латиницей>.mp4`.
4. Читай вывод скрипта: `[face] ... запретная зона` и `[ok]` — хорошо; `[FAIL] текст на лице` (код 3) — укороти `--l1/--l2`, убери `--sub`, перезапусти именно этот ролик; код 4 «лицо занимает весь кадр» — возьми другой клип или только `--l1`; код 5 «нет детектора» — поставь `opencv-python-headless<5` и каскад; `[warn] лицо не найдено` — открой `.check.jpg` и посмотри сам, потом покажи мне. **Ложные лица:** Haar видит «лица» на листьях пальм и орхидеях — на клипе без человека код 3 означает ложную тревогу: другой клип или `--no-face-check` с обязательной проверкой `.check.jpg` глазами.
5. Запускай по одному ролику подряд (не параллельно — скрипт сам считает лица, слабому ноутбуку хватит).
6. После всех: `ffprobe` каждого файла в `reels/out/` — есть видео, звук (если был в исходнике), длительность ≈6 сек.
7. Склей все `*.check.jpg` в один контактный лист `reels/out/00-check-all.jpg` и покажи мне. Дай таблицу: файл → хук → размещение (верх/низ) → статус.
8. Правки я даю словами: «ролик 3 — хук короче», «ролик 5 — другое видео». Каждую правку запиши в `MEMORY.md` одной строкой.

Работай автономно, не переспрашивай разрешения на ffmpeg/ffprobe/python. Закончишь — скажи, сколько заняло времени.

# ПРОМТ Б — говорящая голова: паузы, субтитры, вставки (дома, трек Б)

## Что получишь через 10–20 минут
- Один готовый `.mp4` 1080×1920 из твоей записи (30–90 сек): вырезаны длинные паузы и пустые хвосты, субтитры фразами над головой, 2–4 графические вставки на ключевых фразах, @ник, прогресс-бар, CTA в конце.
- Контрольные кадры на 5 таймкодах (текст не на лице) и список «таймкод → что за вставка».
- Первый рендер HyperFrames качает Chrome (~150 МБ) — 3–5 минут ожидания один раз. Дальше рендер 60-сек ролика — 3–8 минут. На Windows whisper-cli нет — субтитры через `npx hyperframes transcribe`; если не заводится, пропускаем субтитры и делаем только паузы + вставки.

## Промт (заполни поля, вставь целиком)

Смонтируй мне один ролик из говорящей головы по скиллу reels-montazh и моему бренду (`brand/design-system.md`). Окружение — из `.studio-env`. Прочитай эти файлы первыми.

**Мои поля:**
- Файл видео: **`reels/in/[имя файла]`**
- Язык ролика: **[русский / украинский / английский]**
- О чём ролик и главная мысль: **[1–2 предложения]**
- Кодовое слово для CTA: **[из .studio-env или своё]**

**Каким способом:** ТРЕК Б — **HyperFrames** (проект `reels-hf/`). Нужна анимация и синхрон с речью.

**Перед стартом проверь и скажи мне:**
- В видео ЕСТЬ звуковая дорожка — без неё субтитров не будет.
- Видео вертикальное; нет — cover-кроп, не растягивание. 4K → сначала даунскейл до 1080×1920.
- Есть `reels-hf/package.json` (установлен трек Б). Нет — остановись и скажи мне запустить Шаг 8 установщика.
- Есть транскрибатор: Mac — `whisper-cli --help`; Windows или нет whisper-cli — `npx hyperframes transcribe --help`.

**Что сделать:**
1. **Паузы.** Найди тишину: `silencedetect noise=-45dB:d=0.4` (при −30 дБ тихая речь считается паузой и вырезается — голос «пропадает»). Режь ТОЛЬКО паузы длиннее 0.4 сек с запасом 0.2 сек по краям, плюс пустое начало и хвост, и сверь каждый срез с таймкодами whisper: срез не должен попадать внутрь слова. Перед каждым срезом — кадр: убедись, что это пауза. Собери `reels/tmp/cut.mp4` одним ffmpeg (trim/concat).
2. **Транскрипт** — с НАРЕЗАННОГО `cut.mp4` (тогда тайминги точные): модель `medium` для русского/украинского, язык форсируй флагом. Вычитай термины и имена, частая ошибка «промд» → «промпт». Прочитай мне текст — я поправлю слова.
3. **Хук и тезисы.** Сформулируй заголовок-хук (1 строка, ≤6 слов) и 2–4 тезиса — покажи мне ДО сборки, я подтверждаю одним словом.
4. **Кадры лица.** Вытащи кадры на 5 таймкодах, определи зону лица на каждом — она двигается. Запиши в `faces.json`: субтитры и чипы считаются от этих зон.
5. **Композиция** (генерируй python-скриптом из транскрипта): видео фон → субтитры ФРАЗАМИ (2–3 слова) над головой (top ≈210px, Montserrat 900 ≈58px, цвет текста бренда, ключевые слова подчёркнуты акцентом, градиент сверху, сдвиг +0.15с, позиция с учётом лица из `faces.json`) → 2–4 полноэкранные вставки на ключевых фразах (тёмная бренд-панель, схема/карточка/сетка, 2–3 сек, gsap.fromTo от невидимого, субтитры поверх непрерывно) → акцент-чипы на торс (bottom ≈380px), не на голову → лёгкий зум 1.0→1.06 (на контейнер с зумом поставь `data-layout-allow-overflow`, иначе `hyperframes check` ругается на выход за рамку) → @ник + прогресс-бар → CTA-плашка с кодовым словом в конце **на top ≈1120px, чтобы не наезжала на ник внизу**. Каждый `<audio>` с `id`, `class="clip"`, `data-start/duration/track-index`, `src` — иначе без звука.
6. `npm run check` → `snapshot` на 5 таймкодах → проверь «текст не на лице» и что вставки не перекрывают лицо дольше 3 сек → `npm run render`. Первый рендер качает Chrome — это нормально.
7. **Финал всегда в H.264.** HyperFrames отдаёт HEVC, Instagram и Postiz принимают его хуже. Последний шаг по умолчанию:
   `ffmpeg -i reels-hf/out/render.mp4 -c:v h264_videotoolbox -b:v 8M -movflags +faststart -pix_fmt yuv420p -c:a aac -b:a 128k reels/out/<имя>.mp4` (Windows: `-c:v libx264 -preset veryfast -crf 21`).
8. `ffprobe` готового файла: кодек h264, есть аудио, длительность как у `cut.mp4`.
9. Покажи ролик, 5 контрольных кадров и список «таймкод → вставка». Правки словами → в `MEMORY.md`.

Работай автономно, не переспрашивай разрешения на команды. Спрашивай меня только в п. 2 (текст) и п. 3 (хук/тезисы).
