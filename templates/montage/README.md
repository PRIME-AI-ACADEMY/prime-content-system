# Монтаж Reels — что здесь лежит

Эта папка приходит вместе с плагином. Ничего скачивать отдельно не нужно.

| Файл | Зачем |
|---|---|
| `УСТАНОВЩИК-МОНТАЖ.md` | Промт-установщик студии. Вставляешь в новый чат в пустой папке — Клод ставит всё сам (Mac и Windows). |
| `МОНТАЖ-ЗАПУСК.md` | Два промта запуска: А — пачка хук-рилсов, Б — говорящая голова. |
| `tools/build_reel.py` | Скрипт наложения текста: градиент, текст **не на лице** (детекция лиц до и после рендера), CTA внутри плашки, контрольный лист `out.check.jpg`. Установщик копирует его в `tools/` твоего проекта. |
| `tools/check_font.py` | Проверка, что шрифт с кириллицей (без квадратов). |
| `WINDOWS-ГРАБЛИ.md` | Таблица типовых ошибок на Windows и что делать. |

Путь к папке плагина после установки: `~/.claude/plugins/cache/prime-ai/prime-content-system/<версия>/templates/montage/`.
Проще: скажи Клоду «скопируй tools/build_reel.py из папки плагина templates/montage в мой проект».
