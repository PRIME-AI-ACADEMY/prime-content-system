# Карта рутин контент-завода

Рутина = промт, который Claude запускает сам по расписанию. Ты ставишь его один раз.
Дальше завод крутится, а ты нажимаешь одну кнопку в таблице: статус «Утверждено».

## Неделя одним экраном

```
ВОСКРЕСЕНЬЕ  20:00   💻 08  зеркало профиля и фото в Drive      (раз в неделю, ноут открыт)
ВОСКРЕСЕНЬЕ  08:00   ☁️ 01  план на две недели вперёд           → карусель каждый день + 3 рилса, только пустые дни
ПОНЕДЕЛЬНИК  07:00   ☁️ 02  медиа в облаке (Higgsfield), вся неделя разом  → Drive + колонка K, «На утверждении»
ПОНЕДЕЛЬНИК  07:30   💻 03  медиа локально (код + монтаж), вся неделя разом → то же, для строк C и Reels · M (если не успевает — ежедневно 07:30 по одному дню)
КАЖДЫЙ ДЕНЬ  днём    👤 ТЫ  открываешь таблицу, смотришь Drive, ставишь «Утверждено»
КАЖДЫЙ ДЕНЬ  00:30   ☁️ 04  автопостинг «Утверждено» → Postiz    → «Запланировано», id в M
КАЖДЫЙ ДЕНЬ  06:00   ☁️ 05  проверка публикаций                  → «Опубликовано», ссылка в P
КАЖДЫЙ ДЕНЬ  06:30   ☁️ 07  Threads: план + тексты + Postiz      → 6 веток на сегодня
ПОНЕДЕЛЬНИК  09:00   ☁️ 06  аналитика                            → N «Зашло / Не зашло»
```

☁️ облачная — живёт в claude.ai, работает с закрытым ноутбуком.
💻 локальная — живёт в приложении Claude Code, работает только пока приложение открыто.

## Две породы рутин

| | ☁️ Облачная | 💻 Локальная |
|---|---|---|
| Где ставишь | claude.ai → Routines (Scheduled tasks) | приложение Claude Code → папка завода → Routines |
| Когда работает | всегда, ноут закрыт | пока приложение открыто |
| Что видит | коннекторы: Higgsfield, Composio (Drive + Sheets), Postiz | то же + твои файлы: `profile/`, `photos/`, `clips/` |
| Что умеет | план, тексты, картинки и видео Higgsfield, запись в Drive и таблицу, Postiz | + карусели кодом (Pillow), монтаж рилсов (ffmpeg + `build_reel.py`, говорящая голова через HyperFrames по скиллу `reels-montazh`) |
| Чего нет | твоих файлов, ffmpeg, Pillow, Chrome | работы при закрытом ноуте |

Поэтому профиль и фото должны лежать в Drive (рутина 08) — иначе облако тебя «не знает».

## Общие правила (одинаковые во всех промтах)

- **Таблица — мозг.** Вкладка «Контент-план», 16 колонок:
  `A Дата и время (ДД.ММ.ГГГГ ЧЧ:ММ) · B Формат · C Тема · D Хуки · E Ступень Ханта · F CTA / ключ · G Промпт на каждый слайд · H Текст слайдов / Voiceover + заметка о медиа (фото/клип/скрин) · I Воронка · J Функция · Этап · Точка назначения · K Ссылка на медиа (папка Drive + CloudFront-ссылки файлов) · L Статус · M Postiz · N Зашло / Не зашло · O Канал · P Ссылка на публикацию`
  Старые таблицы с колонками I «Медиа из банка» и J «Источник скриншота» читать можно; новые строки пишутся по схеме выше.
- **Формат (B):** `Карусель · T1–T4 · H/C/K` или `Reels · S` (облако, аватар, Seedance ≤15 с) / `Reels · M` (клип из `clips/` + хук, локально) / `Reels · M · говорящая голова` (HyperFrames, локально). Просто `Reels` = `Reels · S`.
- **Факты запуска** (даты эфира, марафона, кодовые слова) — только из `business-dna.md` → «Актуальный запуск». Этот раздел главнее всего остального в профилях.
- **Статусы (L):** `План → На утверждении → Утверждено → Запланировано → Опубликовано`. «Утверждено» ставишь ты. Хочешь без гейта — в промте пиши `ГЕЙТ: нет`, и рутина 02/03 сразу ставит «Утверждено».
- **Никогда дважды:** есть ссылка в K — не перегенерировать; стоит «Запланировано» или «Опубликовано» — не постить. «Нет строк» — это успех.
- **Ошибка на строке** → в N пишется `Ошибка ДД.ММ: коротко`, статус остаётся, рутина идёт дальше. В конце всегда короткий отчёт. Рутина ничего не спрашивает.
- **Postiz:** медиа только по публичной CloudFront-ссылке из K (ссылки Google Drive не подходят), время в UTC, первый запуск — `draft`.
- **Cron облачных рутин — в UTC.** После перехода на зимнее время рутина сработает на час раньше по местному. Пересчёт для Europe/Zurich (лето UTC+2 / зима UTC+1):

  | Местное | UTC летом | UTC зимой |
  |---|---|---|
  | 00:30 | 22:30 (накануне) | 23:30 (накануне) |
  | 06:00 | 04:00 | 05:00 |
  | 07:00 | 05:00 | 06:00 |
  | 08:00 | 06:00 | 07:00 |
  | 09:00 | 07:00 | 08:00 |

  Другой пояс — та же логика: местное минус смещение.

## Как поставить рутину — 3 шага

**☁️ Облачная**
1. claude.ai → слева **Routines** (или Scheduled tasks) → **New**.
2. Вставь ПРОМТ целиком → поставь расписание (время в своём поясе) → Save.
3. Нажми **Run now** и дождись отчёта. Зелёный отчёт → рутина живёт.

**💻 Локальная**
1. Открой приложение Claude Code в папке завода (там лежит `.claude/settings.local.json` из `templates/settings.local.safe.json` — allow-лист команд завода).
2. Напиши в чат: `создай рутину «03 медиа локально», каждый понедельник 07:30, промт:` и вставь ПРОМТ.
3. Открой **Routines** → **Run now** и посиди рядом первый раз. Коннекторы спросят по разу — «Always allow». Дошла до конца без вопросов → готово.

**Локальная рутина всегда идёт в режиме Manual** — режим чата и любые «bypass»-настройки на неё не действуют. Чтобы она не вставала на вопросах, работают ровно четыре правила:
1. **Allow-лист в папке.** `.claude/settings.local.json` из `templates/settings.local.safe.json` в той папке, где рутину создали. Команды из списка (python3, ffmpeg, curl, sips, npx, npm, node, whisper-cli…) проходят молча. Создавай рутину только из папки завода. **Проверь, что в allow-листе стоят id коннекторов `mcp__<uuid>`, а не их названия** (`mcp__postiz` ничего не разрешает) — `setup-check` находит и дописывает их сам.
2. **Простые команды в промте.** Без `$(…)`, без `>` и `>>`, без цепочек через `;`. Одна команда — одно действие. Файлы (лог, список, скрипт) — инструментом записи файлов. На «хитрую» команду приложение даёт только «Allow once», запомнить нельзя — рутина встанет до утра.
3. **Первый запуск — Run now при тебе.** Коннекторы (Higgsfield, Composio, Postiz) спросят по разу — «Always allow», это запоминается на задаче.
4. **Всё, что можно, — в облако.** Облачные рутины claude.ai без shell и без вопросов. Локально оставляй только то, что требует файлов и ffmpeg (03, 08).

## Минимальный набор — хватит, чтобы завод поехал

`01 план` + `02 медиа в облаке` + `04 автопостинг`. Ты только ставишь «Утверждено».

## Полный набор

Минимальный + `05 статус` + `06 аналитика` + `07 Threads` + `03 медиа локально` + `08 зеркало`.
Добавляй по одной рутине в день: поставил → Run now → проверил → следующая.

## Если скилл `schedule` не видит коннекторы
Из Claude Code список коннекторов claude.ai для облачной рутины иногда не загружается. Обход: открой любую уже существующую облачную рутину (`RemoteTrigger list` или claude.ai → Routines) и возьми UUID коннекторов из неё — те же id подставь в новую. Либо создай рутину в claude.ai → Routines руками, вставив промт из файла.
