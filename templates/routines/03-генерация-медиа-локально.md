# 03 · Генерация медиа локально

**Назначение.** Пока ноутбук открыт, рутина делает то, что облако не умеет: карусели кодом (маршрут C, Python + Pillow, твои фото из банка) и рилсы из твоих клипов (`Reels · M`, ffmpeg + скилл `reel-text-overlay`). Складывает в `output/` и в Drive, ставит «На утверждении».

**Когда.** Ежедневно 07:30 (после облачной 02). **Где.** 💻 Локально, приложение Claude Code.

**Что нужно заранее**
- Папка завода с `.claude/settings.local.json` из `templates/settings.local.safe.json` (allow-лист команд). Рутину создаёшь ИЗ ЭТОЙ папки. Рутина всегда идёт в режиме Manual: спасают только allow-лист и простые команды в промте.
- В папке: `profile/design-system.md`, `photos/` + `photo-catalog.md`, `fonts/Montserrat-VF.ttf` (или свой шрифт с кириллицей), `clips/` с 3–10 вертикальными клипами.
- Python + Pillow, ffmpeg, скилл `reel-text-overlay` (в проекте `tools/build_reel.py`).
- Коннекторы: Composio (Sheets + Drive), Higgsfield (только для публичной ссылки на файл).
- Первый запуск — Run now при тебе.

## Как поставить (отличается от облачных)
1. Открой приложение Claude Code в папке завода. Проверь, что там лежит `.claude/settings.local.json` из `templates/settings.local.safe.json`. Нет — скажи: «скопируй шаблон templates/settings.local.safe.json из плагина в .claude/settings.local.json» и открой новый чат.
2. В чате: «создай рутину «03 медиа локально», ежедневно 07:30, вот промт:» + промт.
3. Routines → Run now, посиди рядом. Коннекторы спросят по разу — «Always allow» (запоминается). Если спросила про shell-команду — это «Allow once», запомнить нельзя: найди эту команду в промте и упрости (без `$(…)`, `>`, `;`), пересоздай рутину. Дошла до отчёта без вопросов — готово.

Четыре правила, почему рутина не встаёт: allow-лист в папке · простые команды · первый Run now при тебе · всё остальное в облаке (00-КАРТА).

## Как проверить, что сработало
- В `output/ДД.ММ-тема/` лежат PNG или reel.mp4 + out.check.jpg (текст не на лице).
- В Drive та же папка в «Готовое», в таблице K и L = «На утверждении».
- Рутина ни разу не спросила «Разрешить?».

## Типовые ошибки
| Что видишь | Причина | Что делать |
|---|---|---|
| Рутина висит, ждёт «Разрешить?» на команду | создана из другой папки (нет allow-листа) или в промте `$(…)`, `>`, `;` | пересоздай из папки завода с `settings.local.safe.json`; упрости команду в промте |
| Спрашивает про коннектор | первый вызов инструмента | «Always allow» один раз, дальше молчит |
| Квадраты вместо букв | шрифт без кириллицы | положи Montserrat-VF.ttf с Google Fonts в fonts/ |
| `No module named PIL` | нет Pillow | `python3 -m pip install --user pillow` (Windows: `python`) |
| Текст на лице в рилсе | клип с лицом на весь кадр | другой клип, общий план |
| «Ошибка … нет клипов» | пустая clips/ | положи 3–10 вертикальных клипов |
| Сделала строку «· H» | старый промт | шаг 1: «· H» пропускается |
