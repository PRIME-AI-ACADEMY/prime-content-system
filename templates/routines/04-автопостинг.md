# 04 · Автопостинг

**Назначение.** Ночью рутина находит строки «Утверждено» с медиа и ставит их в расписание Postiz на дату и время из колонки A. Пишет id поста в M, статус «Запланировано». Публикует сам Postiz из своего облака.

**Когда.** Ежедневно 00:30. **Где.** ☁️ Облако.

**Что нужно заранее**
- Postiz: каналы Instagram (и Threads, если хочешь) подключены в app.postiz.com. Коннектор Postiz в claude.ai.
- Composio (Sheets + Drive).
- Публичные ссылки на файлы в K (их пишут рутины 02/03). Ссылки Google Drive Postiz не принимает.
- Первый запуск — `РЕЖИМ: draft`. Проверил календарь Postiz — меняешь на `schedule`.

```
Ты — рутина «04 автопостинг» контент-завода Angelina (PRIME AI). Работай сама, ничего
не спрашивай. Коннекторы: Postiz, Composio (Google Sheets + Drive).

ДАННЫЕ
- Таблица 1sdIQe_iHqAk49Bb1byY6OittHvtm2US3Hgb7s7xUCPo, вкладка «Контент-план».
  A Дата и время · B Формат · C Тема · D Хуки · F CTA / ключ · H Текст · K Ссылка на медиа ·
  L Статус · M Postiz · N Зашло · O Канал.
- Postiz: Instagram integrationId cmqmt1fb702kbp40yafh6pjd6, Threads cmu06nbr503qllm0yz9t3vxnt.
- Часовой пояс Europe/Zurich (лето UTC+2, зима UTC+1). Postiz принимает только UTC.
- Ник @angelinaa.kh. Кодовое слово СИСТЕМА. Хэштеги (до 5): #контентзавод #нейросети
  #claude #автоматизация #маркетинг.
- РЕЖИМ: draft   (после проверки замени на schedule)

ШАГИ
1. Прочитай таблицу. Возьми строки, где L = «Утверждено», K не пустая, M пустая.
   Строки «Запланировано» и «Опубликовано» не трогай. Подходящих нет —
   напиши «нет строк» и закончи.
2. Для каждой строки собери медиа. В K после ссылки на папку Drive идут публичные
   ссылки на файлы по порядку — используй их. Публичных ссылок нет — скачай файлы из
   папки Drive через Composio (временная ссылка) и передай её в uploadFromUrlTool;
   если Postiz отказал — Higgsfield media_import_url → публичная ссылка → uploadFromUrlTool.
   Карусель = несколько картинок по порядку; рилс = одно видео.
3. Подпись: первая строка = хук (первый вариант из D), 2–3 короткие строки по теме,
   CTA из F с кодовым словом, пустая строка, хэштеги. Не пересказывай содержимое
   слайдов и рилса. На «ты», настоящее время, без женского рода, без «не X, а Y».
4. Время: возьми A (Europe/Zurich), переведи в UTC. В A нет времени — 11:00.
   Дата уже прошла — ближайший час, кратный 30 минутам, плюс 2 часа.
5. integrationSchedulePostTool: канал по O (пусто или «Instagram» → Instagram;
   «Threads» → Threads; «Instagram+Threads» → оба). Для Instagram: рилс — settings
   post_type = post (Reel); карусель — картинки в attachments. Для Threads: подпись
   до 500 знаков, каждая строка в <p>…</p>, первая картинка. type = РЕЖИМ.
6. Проверь через postsListTool, что пост стоит на нужную дату. Запиши M = id поста +
   дата UTC, L = «Запланировано».
7. Отчёт: дата, тема, канал, UTC-время, режим (draft/schedule), ссылка предпросмотра.

ОШИБКИ
- Postiz вернул ошибку на строке (медиа недоступно, не тот канал, длина) → N = «Ошибка
  ДД.ММ: коротко», L и M не меняй, следующая строка.
- Каналов нет в integrationList → остановись: «подключи канал в app.postiz.com».
- Не удалось записать в таблицу → выведи id постов в отчёт.
- Никогда не завершай молча.
```

## Как проверить, что сработало
- app.postiz.com → Launches → календарь: пост стоит на нужный день и время (твой пояс), медиа на месте, подпись цела.
- В таблице M заполнена, L = «Запланировано».
- В режиме draft пост серый, никуда не уходит. Всё верно — в промте меняешь `РЕЖИМ: draft` на `РЕЖИМ: schedule`, сохраняешь рутину.

## Типовые ошибки
| Что видишь | Причина | Что делать |
|---|---|---|
| «медиа недоступно» | в K только ссылка Drive без публичных | перезапусти 02/03 для строки (очисти K) или дай публичную ссылку |
| Пост встал не в то время | пояс | в промте есть пояс; проверь, что A содержит время |
| «канал не найден» | Instagram отвалился в Postiz | app.postiz.com → канал → Reconnect |
| Рилс встал как фото | нет post_type | шаг 5, settings post_type = post |
| Threads: >500 знаков | длинная подпись | рутина режет сама; проверь шаг 5 |
| Пост ушёл в реальный аккаунт в первый раз | РЕЖИМ уже schedule | первый запуск всегда draft |
