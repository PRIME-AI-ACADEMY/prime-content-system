# 06 · Аналитика «Зашло / Не зашло»

**Назначение.** Раз в неделю рутина смотрит охваты и сохранения постов, которым больше 3 дней, и пишет в N вердикт «Зашло» или «Не зашло» плюс одну строку почему. Рутина 01 читает N и следующую неделю планирует умнее.

**Когда.** Понедельник 09:00. **Где.** ☁️ Облако.

**Что нужно заранее**
- Коннекторы: Composio (Sheets); источник цифр — Postiz (если отдаёт статистику) или Metricool (если подключён).
- Если ни один сервис цифры не отдаёт — ты раз в неделю вписываешь в N «охват 3400 · сохр 120» руками, рутина превращает это в вердикт.

```
Metricool, если подключён.

ДАННЫЕ
- Таблица 1sdIQe_iHqAk49Bb1byY6OittHvtm2US3Hgb7s7xUCPo, вкладка «Контент-план».
  A Дата и время · B Формат · C Тема · E Ступень · L Статус · M Postiz · N Зашло / Не зашло ·
  P Ссылка на публикацию.
- Аккаунт Instagram @angelinaa.kh. Часовой пояс Europe/Zurich.

ШАГИ
1. Прочитай таблицу. Возьми строки, где L = «Опубликовано», дата A старше 3 дней,
   N пустая или N содержит только цифры («охват … · сохр …») без слова «Зашло».
   Подходящих нет — напиши «нет строк» и закончи.
2. Цифры по каждому посту (охват, сохранения, лайки, комментарии) возьми в таком
   порядке: Postiz по id из M → Metricool (getAnalyticsDataByMetrics, если есть) →
   цифры, уже вписанные в N руками. Ничего нет — N = «нет данных ДД.ММ», дальше.
3. База сравнения: медиана охвата последних 10 строк «Опубликовано» с цифрами.
   Строк с цифрами меньше 5 — база = среднее по тому, что есть.
4. Вердикт: охват ≥ 1.3 × база ИЛИ сохранения ≥ 3% охвата → «Зашло»; охват ≤ 0.7 × база
   → «Не зашло»; между — «Средне».
5. N = «Зашло · охват 4 800 · сохр 210 · <одна строка почему: формат/тема/хук/ступень>».
   Одна строка, без переносов.
6. Отчёт: таблица дата · формат · тема · вердикт, и 3 вывода на следующую неделю
   (какой тип карусели, какая ступень, какой хук работают).

ОШИБКИ
- Источник цифр не отвечает → пропусти строку, N не трогай, напиши об этом.
- Не удалось записать в таблицу → выведи вердикты в отчёт.
- Никогда не завершай молча.
```

## Как проверить, что сработало
- У постов старше 3 дней в N стоит «Зашло / Средне / Не зашло · цифры · почему».
- В отчёте 3 вывода. В следующее воскресенье рутина 01 их учитывает (темы смещаются к тому, что зашло).

## Типовые ошибки
| Что видишь | Причина | Что делать |
|---|---|---|
| «нет данных» во всех строках | ни Postiz, ни Metricool не отдают статистику | раз в неделю вписывай цифры в N руками: «охват 3400 · сохр 120» — рутина доделает |
| Все посты «Средне» | мало данных, база плавает | нормально первые 2 недели |
| Вердикт по посту, которому 1 день | дата A без года | в A всегда «ДД.ММ.ГГГГ ЧЧ:ММ» |
