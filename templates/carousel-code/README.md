# Карусель кодом (маршрут C)

JSON → PNG 1080×1350. Запуск: `python3 build_c.py examples/t1-text.json` (Windows: `python`). Нужны Pillow (+ opencv-python-headless для детекции лица на фото), шрифт Montserrat-VF.ttf в `fonts/` или в `profile/`. Типы T1–T4 — см. examples/. Результат: `out/<имя>/slide-XX.png` + `00-contact.jpg` (контрольный лист — смотри глазами).


## Детектор лиц (обновление 26.09)
Сначала YuNet (`fonts/face_detection_yunet_2023mar.onnx`, копия в `models/`): видит лицо в три четверти, с руками у лица, в наклоне. Haar-каскад — запасной, только анфас, и его срабатывания в нижней части кадра отбрасываются (колени и руки). Если лицо не найдено ни в одном кадрировании или везде попадает под текст — текст кладётся на сплошную бренд-плашку сверху, фото снизу (`band`), на фото текст не рисуется никогда.
