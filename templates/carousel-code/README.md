# Карусель кодом (маршрут C)

JSON → PNG 1080×1350. Запуск: `python3 build_c.py examples/t1-text.json` (Windows: `python`). Нужны Pillow (+ opencv-python-headless для детекции лица на фото), шрифт Montserrat-VF.ttf в `fonts/` или в `profile/`. Типы T1–T4 — см. examples/. Результат: `out/<имя>/slide-XX.png` + `00-contact.jpg` (контрольный лист — смотри глазами).
