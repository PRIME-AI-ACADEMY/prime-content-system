# Сайт контент-плана из Google-таблицы

Один файл `index.html` + один файл настроек `config.js`. Сайт сам читает твою таблицу «Контент-план» и показывает её как красивую панель: недели, дни, карточки постов, текст слайдов с кнопкой «Копировать», статусы, очередь Higgsfield. Поменяла статус в таблице — через 5 минут видно на сайте. Ничего устанавливать не нужно.

Живой пример: https://prime-content-plan.vercel.app

## Что нужно

- Google-таблица, которую сделал скилл `content-plan` (вкладка «Контент-план», 16 колонок A–P).
- Node.js на компьютере (для команды `npx`). Проверить: в терминале `node -v`. Нет — скачай с nodejs.org, «LTS», далее-далее-готово.

## Шаг 1. Открой таблицу для чтения по ссылке

1. Открой свою таблицу в Google Sheets.
2. Справа вверху кнопка **«Настройки доступа»** (Share).
3. Внизу окна «Общий доступ» → вместо «Ограниченный» выбери **«Все, у кого есть ссылка»**.
4. Роль справа — **«Читатель»**. Нажми «Готово».

Всё. Сайт читает таблицу через эту ссылку. Редактировать её по-прежнему можешь только ты.

## Шаг 2. Впиши ID таблицы в config.js

Открой таблицу. В адресной строке браузера адрес такого вида:

```
https://docs.google.com/spreadsheets/d/1sdIQe_iHqAk49Bb1byY6OittHvtm2US3Hgb7s7xUCPo/edit#gid=404736922
                                        └──────────── это SHEET_ID ────────────┘          └─ это gid ─┘
```

Открой `config.js` в любом текстовом редакторе (TextEdit, Блокнот, VS Code) и замени:

```js
SHEET_ID: 'вставь_сюда_свой_ID',
TABS: [
  { name: 'Контент-план', gid: 0, channel: 'ig' },
],
```

- `SHEET_ID` — длинная строка между `/d/` и `/edit`.
- `gid` — число после `#gid=` в адресе, когда открыта нужная вкладка. У первой вкладки обычно `0`.
- `name` — как называется вкладка внизу таблицы.
- `channel` — куда идут посты с этой вкладки: `'ig'` (Instagram), `'th'` (Threads), `'tg'` (Telegram). Если в строке заполнена колонка **O «Канал»**, она важнее.

Несколько вкладок (например отдельная для Threads) — добавь ещё строку в `TABS`.

## Шаг 3. Выложи сайт (одна команда)

Открой терминал в папке с файлами (Mac: правый клик по папке → «Новый терминал в папке»; Windows: в Проводнике в адресной строке набери `cmd`).

```
npx vercel --prod --yes
```

Первый раз Vercel попросит войти: выбери **Continue with GitHub** или **Email**, подтверди в браузере, вернись в терминал. На все вопросы жми Enter (значения по умолчанию). Через 20–30 секунд в терминале появится адрес вида `https://content-dashboard-xxxx.vercel.app` — это твой сайт. Открой его на телефоне, сохрани на главный экран.

Обновить сайт после правок в `config.js` — та же команда.

**Посмотреть локально без деплоя.** Открывать `index.html` двойным кликом нельзя: Google не отдаёт таблицу странице с адресом `file://`. Вместо этого в папке запусти `npx serve .` и открой `http://localhost:3000`.

## Шаг 4. Свои цвета и ник

В `config.js`:

```js
BRAND: {
  name:   'МОЙ БРЕНД',      // текст слева вверху; часть после « · » станет золотой
  handle: '@мой_ник',
  colors: {
    pine:  '#00311e',   // основной тёмный цвет фона
    cream: '#fef7e5',   // светлый текст
    gold:  '#e8b96a',   // акцент: кнопки, активные вкладки
  },
},
TITLE:   'Мой бренд — Контент-платформа',   // заголовок вкладки браузера
TAGLINE: 'Подпись под большим заголовком на главной.',
```

Цвета бери из своей дизайн-системы (`profile/design-system.md`). Все оттенки фона и карточек сайт посчитает сам от `pine`.

## Что сайт берёт из таблицы

| Колонка | Что показывает |
|---|---|
| A Дата | день в календаре. Понимает `2026-09-17`, `17.09.2026`, `17.09`, `17 сент.`, `9/17/2026` |
| B Формат | бейдж Карусель / Reels / Пост / Ветка Threads; маршрут `H` = попадает в очередь Higgsfield |
| C Тема | заголовок карточки |
| D Хуки | подзаголовок карточки + блок «Хуки» в окне поста с кнопкой «Копировать» |
| E Ступень Ханта, F CTA | теги и золотая плашка |
| G Higgsfield-промпт / Дизайн | промт в очереди Higgsfield и в окне поста (свёрнуто) |
| H Voiceover / Текст слайдов | режется на слайды по нумерации `01 …`, `02 …` (или по пустым строкам) — у каждого слайда своя кнопка «Копировать» |
| K Ссылка на медиа (Drive) | кнопка «Открыть медиа в Google Drive» (если это ссылка) |
| L Статус | План · На утверждении · Утверждено · Запланировано · Опубликовано |
| M Postiz | бейдж «⟳ Postiz»; если там ссылка на пост — кнопка «Открыть пост» |
| O Канал | Instagram / Threads / Telegram — на какую вкладку сайта попадает строка |
| P Ссылка на публикацию | кнопка «Открыть пост» / «Открыть Reels» |

Строки без даты (разделители, заметки) сайт пропускает.

## Если что-то не так

**«Не могу прочитать таблицу» / в консоли CORS или 401.**
Таблица не открыта по ссылке. Повтори Шаг 1: «Все, у кого есть ссылка» → Читатель. Подожди минуту и нажми ↻ на сайте.

**Показывает «Таблица пуста», хотя строки есть.**
1. Не та вкладка: проверь `gid` в `config.js` (число после `#gid=` в адресе, когда открыта нужная вкладка).
2. Даты не читаются: в колонке A должны быть даты вида `2026-09-17`, `17.09.2026` или `17 сент.`. Текст типа «понедельник» сайт не поймёт.

**Посты попали не на ту неделю или не в тот год.**
Если в дате нет года («17 сент.»), сайт берёт ближайший год к сегодняшнему дню. Хочешь точно — пиши год: `17.09.2026`.

**Открыла index.html двойным кликом, и пусто.**
Так и должно быть: адрес `file://` Google не обслуживает. Запусти `npx serve .` или задеплой (Шаг 3).

**Vercel спрашивает «Set up and deploy?», «Which scope?», «Link to existing project?».**
Enter, Enter, `N`, Enter. Имя проекта — любое, Enter.

**Сайт открывается, но Vercel просит войти (адрес прыгает на vercel.com/sso-api).**
На проекте включена защита деплоев. В Vercel: проект → Settings → Deployment Protection → **Vercel Authentication → Disabled** → Save. Через минуту сайт открыт всем.

**Хочу красивый адрес.**
В Vercel: проект → Settings → Domains → добавь `имя.vercel.app` (бесплатно) или свой домен.

## Как это устроено (для любопытных)

Сайт запрашивает `https://docs.google.com/spreadsheets/d/<SHEET_ID>/export?format=csv&gid=<gid>` — это официальный CSV-экспорт Google, работает для таблиц с доступом по ссылке и не требует ключей. Никакого сервера, никакой базы: один HTML-файл, который раз в 5 минут перечитывает таблицу. Кнопка ↻ вверху делает это сразу.
