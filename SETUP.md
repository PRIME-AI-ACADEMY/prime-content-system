# Контент-завод на Claude · Установка с нуля, шаг за шагом (v4)
**Тренинг PRIME AI «Контент-завод за один день»**

Результат: твоя система, которая по одному промту готовит контент на неделю (тексты, карусели, видео), складывает в твою Google-таблицу и публикует по расписанию.

**Как пользоваться гайдом:** иди строго по шагам, после каждого шага есть ✅ Проверка. Если что-то пошло не так — скопируй текст ошибки и спроси у Клода, он чинит сам. Пользуешься Windows — после каждого шага загляни в раздел **«Windows: что иначе»** в конце.

## 📖 Словарик (30 секунд)

- **Claude Code** — режим Claude, где он умеет работать с файлами и запускать программы. Наш «цех».
- **Терминал** — окно, куда вводят текстовые команды. Нужен 3 раза за весь гайд.
- **Плагин** — набор навыков (скиллов) контент-завода, ставится двумя командами.
- **Скилл** — один навык внутри плагина: «собери карусель», «проверь установку». Всего их 19.
- **Коннектор (MCP)** — «провод» между Claude и сервисом (Higgsfield, Google, Postiz). Подключается кнопками, привязан к твоему аккаунту.
- **Фундамент** — твой стратегический паспорт (кто клиент, что продаёшь, как говоришь). Живёт в папке `profile/`, его читают все скиллы.

## Шаг 3. Устанавливаем программы (20 мин)

### 3.1. Приложение Claude
[claude.ai/download](https://claude.ai/download) → скачай для своей системы → установи → войди в свой Pro-аккаунт.

**Версия важна.** Команды `/plugin` работают в приложении версии **2.1.193 и новее**. Как проверить: открой раздел **Code**, в строке ввода набери `/status` и отправь — версия в первой строке. Или меню приложения → **About Claude**. Старее → в том же меню **Check for updates**, обнови, полностью перезапусти.

✅ Проверка: `/status` показывает версию ≥ 2.1.193.

### 3.2. Python + Pillow (карусели кодом, без браузера)
Карусели маршрутом «код» рисует Python-библиотека Pillow. Браузер для этого не нужен.

**Mac** (Python уже стоит):
1. Открой Терминал: `Cmd + Пробел`, набери `Терминал`, Enter.
2. Проверь: `python3 -c "import PIL; print(PIL.__version__)"`. Вывело число — Pillow есть, шаг закончен.
3. Нет — поставь: `python3 -m pip install --user pillow`.
4. Если в ответ пришло `externally-managed-environment` — вставь по очереди:
```
python3 -m venv ~/.reels-venv
~/.reels-venv/bin/pip install pillow
```
   и скажи Клоду один раз: «для Python-скриптов используй `~/.reels-venv/bin/python`».

**Windows:**
1. Пуск → набери `PowerShell` → Enter.
2. Проверь: `python -c "import PIL; print(PIL.__version__)"`. Вывело число — готово.
3. Ответ «python не найден» → `winget install Python.Python.3.12`, закрой и открой PowerShell, повтори проверку.
4. Python есть, Pillow нет → `python -m pip install --user pillow`.

✅ Проверка: `python3 -c "import PIL; print(PIL.__version__)"` (Windows: `python …`) → число вроде `11.0.0`.

### 3.3. ffmpeg (монтаж видео)

**Mac:**
1. В Терминале вставь и нажми Enter (установка Homebrew):
```
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```
   Спросит пароль от Мака — вводи (символы не отображаются, это нормально), Enter.
2. Затем вторая команда:
```
brew install ffmpeg
```

**Windows:**
1. В PowerShell вставь и нажми Enter:
```
winget install Gyan.FFmpeg
```
   Если «winget не найден» — открой Microsoft Store, обнови «App Installer», повтори.
2. **Полностью закрой и открой приложение Claude** — иначе оно не увидит ffmpeg.

✅ Проверка: `ffmpeg -version` → строки с версией.

### 3.4. Голосовой ввод (очень рекомендую)
Печатать промты голосом в 3–4 раза быстрее.
- **Wispr Flow** — [wisprflow.ai](https://wisprflow.ai), Mac и Windows: горячая клавиша → говоришь → текст в любом поле. Есть бесплатный план.
- Бесплатно встроенное: **Mac** — Настройки → Клавиатура → Диктовка (вкл), вызов двойным нажатием 🎤/Fn. **Windows** — `Win + H`.

### 3.5. Что ставить НЕ нужно
Никаких «программ для дизайна и моушена»: карусели рисует Python + Pillow, монтаж — ffmpeg, картинки/видео/анимации генерит Higgsfield в облаке. **Google Chrome не нужен** — только если сам захочешь путь «HTML → PNG/PDF». **Node.js не нужен** — только для HyperFrames (анимации кодом, см. [ADVANCED.md](ADVANCED.md)).

## Шаг 6. Разрешения — один раз и навсегда (5 мин)

Клод спрашивает «Разрешить?» на каждую новую команду. Для завода это мешает дважды: ты кликаешь по сто раз, а ночная рутина на открытом ноутбуке **встаёт и ждёт клика**. Решение — готовый файл разрешений в папке проекта. Два режима, выбери один:

**Режим 1 · «Безопасный»** (рекомендуем для старта). Разрешено всё, что нужно заводу (Python, ffmpeg, curl, Node, git, чтение/запись файлов, коннекторы Higgsfield/Composio/Postiz). Запрещено опасное (`rm -rf`, `sudo`, `git push`, ключи). На незнакомую команду Клод ещё спросит.

Скажи Клоду в чате:
```
Скопируй файл шаблона из плагина templates/settings.local.safe.json
в папку проекта как .claude/settings.local.json и покажи, что получилось.
```

**Режим 2 · «Автопилот»** — для папки завода, где ходят рутины. Клод не спрашивает ничего, кроме запрещённого списка. Включай только в отдельной папке контент-завода, не в папке с рабочими документами.
```
Скопируй файл шаблона из плагина templates/settings.local.autopilot.json
в папку проекта как .claude/settings.local.json.
```
После этого **закрой и открой чат** (новая сессия) — режим подхватывается на старте. Приложение один раз покажет предупреждение про режим без запросов — подтверди.

**Коннекторы claude.ai** (Higgsfield, Composio, Postiz) в режиме 1 могут спросить один раз на каждый инструмент — жми **«Always allow»**, ответ записывается в тот же файл. В режиме 2 не спрашивают.

✅ Проверка: скажи «сделай тестовую картинку 1080×1350 через Python и сохрани в out/» — Клод делает это **без единого вопроса**.

**Два правила, без которых рутина всё равно встанет (проверено на живом прогоне):**
1. **Рутина работает в той папке, где её создали.** Открой чат именно в папке завода (с файлом разрешений) и уже оттуда говори «создай рутину…». Рутина, созданная из другой папки, будет спрашивать разрешения по правилам той папки.
2. **В режиме 1 Клод всё равно спросит на «хитрые» команды** — подстановки `$(...)`, запись через `>`, цепочки с `sudo`. Даже если `printf` разрешён, `printf "$(date)" > файл` покажет диалог. Поэтому для папки с рутинами используй **режим 2 «Автопилот»** — там таких остановок нет. Режим 1 хорош для ручной работы в чате.

⚠️ Интерфейсы обновляются. Если кнопка называется иначе — ищи слова «MCP», «Integrations», «API» или спроси Клода.

## Шаг 9. Фундамент (30–40 мин; на тренинге — 10 мин)

Фундамент — первый шаг. Без него контент-план строить не на чем.

1. Открой **новый чат** в Claude Code.
2. Открой [PROMPTS.md](PROMPTS.md) и вставь целиком **промт №1** (полное интервью). На тренинге, когда время ограничено, — **промт №2** (быстрый режим, 10 минут): впиши в него нишу, продукт, цену, цель и откуда приходят клиенты.
3. Отвечай на вопросы (по 3–4 за раз, с вариантами). Потом Клод покажет каркас — поправь, что неправда.
4. На выходе: `profile/foundation.html` (открой в браузере — паспорт проекта с навигацией) и профили в `profile/`.
5. Сразу после — скажи: **«запусти design-system-builder»**. Назови любимые цвета и шрифты или выбери из 2–3 палитр. Появится `profile/design-system.md`.

Есть свои материалы (распаковка, анализ ЦА)? Положи их в папку `материалы/` и добавь к промту первой строкой: «Мои материалы приложены. Прочитай их, спрашивай только про то, чего в них нет».

✅ Проверка: в папке `profile/` лежат `foundation.html`, `business-dna.md`, `audience.md`, `hunt-ladder.md`, `offer.md`, `design-system.md`.

Голос бренда (`tone-of-voice.md`) — отдельно: «запусти tone-of-voice-builder», приложи 3–10 своих текстов.

## Шаг 10. Первый контент-план и первая карусель (30 мин)

Новый чат → **промт №4** из [PROMPTS.md](PROMPTS.md). Клод покажет план в чате → утверждаешь → образец из 2 постов → утверждаешь → таблица в Google Sheets.

Первую карусель попроси так: **«собери карусель по строке 1 плана»**. В колонке «Формат» стоит тип и маршрут, например `Карусель · T1 · C` — это код Python + Pillow, картинки появятся в `output/`, ссылка и статус «На утверждении» — в таблице.

✅ Проверка дня: в `output/` (и в Google Drive, если подключён) — готовая карусель, в таблице — план на неделю.

## Шаг 11. Телефон: что можно, что нельзя

Поставь приложение **Claude** на телефон (iOS/Android), войди в тот же аккаунт.

**Можно с телефона:** тексты и идеи, генерации Higgsfield (облако), карусели через Canva (маршрут K), облачные Code-сессии, утверждение в приложении Google Таблицы (статус «Утверждено»), ответы на кодовое слово в директе.
**Нельзя с телефона:** установить плагин, собрать карусель кодом (нужен Python на компьютере или облачная Code-сессия), монтаж ffmpeg.
Формула: **завод строим на ноутбуке — управляем с телефона.**

## Шаг 12. Автопостинг: четыре варианта

| Вариант | Цена | Что умеет |
|---|---|---|
| **A. Postiz** (по умолчанию) | триал, потом платно; self-hosted бесплатно | Полный автопилот: Клод сам ставит посты в расписание через коннектор. Instagram + Threads |
| **B. Metricool** | бесплатно с лимитами (1 бренд, ограничение постов в месяц) | Тоже MCP, тоже автомат. Бесплатная альтернатива |
| **C. Meta Graph API** | бесплатно | Полный авто Instagram по токену. Нужно приложение в Meta for Developers — для тех, кто готов повозиться |
| **D. Ручной препост** | бесплатно | Клод готовит подписи и медиа → ты за 2 минуты ставишь в Meta Business Suite |

Три правила, из-за которых ломается 90% автопостинга:
1. **Медиа — публичная ссылка.** Файл в Drive с доступом «все, у кого есть ссылка». Клод сам сделает прямую ссылку.
2. **Время в Postiz — UTC.** Скажи Клоду свой часовой пояс один раз, он переводит сам.
3. **Первый пост — черновик.** Скажи «запланируй как draft» — ничего не улетит, посмотришь в календаре Postiz.

Запуск: «строки со статусом Утверждено — запланируй через Postiz как черновик». Понравилось → «теперь по-настоящему».

- **Терминал** = PowerShell. Команды из блоков вставляй по одной.
