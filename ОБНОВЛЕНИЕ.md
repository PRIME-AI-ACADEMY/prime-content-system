# Как обновить плагин «Контент-завод» до версии 0.13

Для тех, кто ставил плагин на первом контент-заводе 11 июля. Занимает 3 минуты, терминал нужен только для двух команд, остальное делает Claude.

## Что появилось с июля

- 21 скилл вместо 19: добавились `funnels` (вечные воронки, кодовые слова, прогрев по дням) и `reels-montazh` (монтаж хук-рилсов и говорящей головы).
- Карусели кодом с твоими реальными фото: детектор лиц, текст никогда не ложится на лицо.
- Проверенный промт для Higgsfield, лист-эталон лица и нейрофотосессия.
- Контент-план на 2 недели с воронками, сайт-дашборд, который читает таблицу живьём.
- 8 готовых рутин: медиа по понедельникам на всю неделю, автопостинг каждую ночь.
- `setup-check`: проверяет программы и коннекторы и сам дописывает их id в разрешения.
- Единый промт участника на 16 шагов. Все промты и рутины лежат в папке Google Drive:
  https://drive.google.com/drive/folders/1r48G4a8uUXWXs5uzcV-IVfzm5lv4m0P8

## Способ 1. Терминал в приложении (рекомендую)

Так обновление проходит одинаково на Mac и Windows, и ты сразу видишь, какая версия встала.

**Шаг 1.** Открой приложение Claude → вкладка **Code** → **Open folder** → выбери папку своего завода (в июле мы называли её `Контент-завод`).
**Шаг 2.** Нажми значок терминала **`>_`** справа вверху. Откроется панель с командной строкой.
**Шаг 3.** Вставь первую команду и нажми Enter:

```
claude plugin marketplace update prime-ai

```
Увидишь `✔ Successfully updated marketplace: prime-ai`.
**Шаг 4.** Вставь вторую команду и нажми Enter:

```
claude plugin update prime-content-system@prime-ai

```
Увидишь `✔ Plugin "prime-content-system" updated from 0.10.0 to 0.13.0`. Цифра слева может отличаться, справа должно быть `0.13.0`.
**Шаг 5.** **Полностью закрой приложение и открой заново.** На Mac это Cmd+Q, на Windows выход через значок в трее. Просто закрыть окно недостаточно, плагин подхватывается при запуске.
**Шаг 6.** Проверка. В новом чате напиши:

```
какая версия prime-content-system и сколько в нём скиллов?

```
Правильный ответ: 0.13.0, 21 скилл.

Если на шаге 3 терминал пишет `Marketplace "prime-ai" not found`, плагин в июле был поставлен иначе. Тогда поставь заново, это те же три минуты:
```
claude plugin marketplace add PRIME-AI-ACADEMY/prime-content-system
```
```
claude plugin install prime-content-system@prime-ai
```
и дальше шаг 5.

## Способ 2. Кнопка в приложении

В приложении Claude: **Customize → Plugins** → найди `prime-content-system` → кнопка **Update**. После этого обязательно закрой и открой приложение и сделай проверку из шага 6. Если версия осталась старой или кнопки нет, иди по способу 1: он обновляет и каталог, и плагин, кнопка иногда обновляет только плагин из старого каталога.

## После обновления: один промт, чтобы проект подхватил новое

Плагин обновился, но в твоей папке проекта остались июльские файлы. Вставь в чат одним сообщением:

```
Обнови мой проект под плагин prime-content-system 0.13. Сделай сам, по шагам, проверяя результат командой:
1. Скопируй из папки плагина templates/carousel-code/build_c.py, lab_common.py и models/face_detection_yunet_2023mar.onnx в tools/, а templates/montage/tools/build_reel.py тоже в tools/. Старые версии перезапиши.
2. Скопируй templates/settings.local.safe.json в .claude/settings.local.json. Если файл уже есть, сохрани мои id коннекторов mcp__… и только добавь недостающие строки.
3. Проверь, что стоит "opencv-python-headless<5" и Pillow; чего нет, поставь.
4. Запусти скилл setup-check и покажи таблицу ✅/❌.
5. Открой templates/routines/00-КАРТА-РУТИН.md и скажи, какие из моих рутин надо перевести на новый ритм: 02 и 03 теперь по понедельникам, 01 раз в две недели.
Скажи мне перезапустить чат, когда settings.local.json изменится.
```

Дальше работаешь как обычно: `content-plan`, `carousel`, `reels`. Единый промт участника и все промты рутин лежат в папке Drive по ссылке выше.

## Threads-плагин (в июле его не было)

Ставится отдельно, тем же способом, в том же терминале:
```
claude plugin marketplace add PRIME-AI-ACADEMY/prime-threads-system
```
```
claude plugin install prime-threads-system@prime-threads
```
Закрыть и открыть приложение, в чате: «запусти threads-setup».

## Если что-то пошло не так

| Что видишь | Причина | Что делать |
|---|---|---|
| Команда `/plugin …` в чате не работает | команды плагина живут в терминале, а не в чате | нажми `>_` и вставь команду туда |
| `command not found: claude` | открыт системный терминал, а не терминал приложения | закрой его, нажми `>_` внутри приложения Claude |
| После обновления версия старая | приложение не было закрыто полностью | Cmd+Q на Mac, выход из трея на Windows, открыть заново |
| Терминал спрашивает `Allow?` | обычный запрос разрешения | нажми Allow |
| Windows: команда не вставляется | буфер обмена в терминале | правая кнопка мыши → Paste или Shift+Insert |
| `Checking for updates… already up to date`, но скиллов 19 | каталог не обновился | сначала `claude plugin marketplace update prime-ai`, потом `claude plugin update …` |

## Как обновляться дальше

Каждый раз, когда я пишу «вышла версия X», это те же две команды в терминале и перезапуск приложения. Проверка одна: спросить Claude версию.
