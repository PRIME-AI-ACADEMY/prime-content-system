# Готовые промты

Копируй целиком в новый чат Claude Code, в папке проекта с установленным плагином.

---

## 1. ФУНДАМЕНТ — главный промт воркшопа

Выдаёт стратегический паспорт: ЦА, отстройку, смыслы, оффер, путь клиента, стратегию. Одним HTML-документом с навигацией.

```
Запусти скилл foundation и собери мой стратегический фундамент.

Сначала задай мне вопросы — по 3–4 за раз, с вариантами ответа.
Потом покажи сжатый каркас на утверждение, и только после моего «да» собирай документ.

На выходе жду HTML-файл с боковой навигацией по шести блокам:
1) анализ ЦА по сегментам, 2) идеи контента и отстройка, 3) карта продукта и смыслов,
4) продукт, наполнение и оффер, 5) путь клиента от холодного до горячего,
6) стратегия с нуля к цели.

Требования к тексту:
— каждый тезис с маркером ФАКТ / ВЫВОД / ГИПОТЕЗА
— точка А каждого сегмента — монологом от первого лица, живой речью
— три слоя страха: поверхностный, средний, глубинный
— в каждом блоке минимум одно число, срок или цена
— отстройка через слабое место конкурентов и свободные зоны рынка
— антигарантия: чего продукт честно НЕ даёт
— в конце раздел с пробелами: чего не хватает и что проверить на практике
— без воды и без канцелярита, живым языком
```

**Если материалы уже есть** (распаковка, анализ ЦА, карта продукта) — добавь первой строкой:

```
Мои материалы приложены. Прочитай их, спрашивай только про то, чего в них нет.
```

## 2. БЫСТРЫЙ ВАРИАНТ для живой демонстрации

Когда времени 10 минут и надо показать результат на экране.

```
Скилл foundation, быстрый режим. Два круга вопросов, дальше сразу документ.
Моя ниша: [НИША]. Продаю: [ПРОДУКТ] за [ЦЕНА]. Цель: [ЧИСЛО] к [ДАТА].
Клиенты приходят: [ОТКУДА].
Собери фундамент и отдай HTML с навигацией.
```

---

## 3. ДОРАБОТКА одного блока

Когда фундамент собран, а один блок хочется глубже.

```
Открой мой фундамент и переделай блок [НОМЕР].
Что не так: [ЧТО ИМЕННО].
Пересобери только этот блок и обнови HTML-файл, остальное не трогай.
```

---

## 4. КОНТЕНТ-ЗАВОД — следующий этап

Запускать только после готового фундамента.

```
Фундамент готов, профили в profile/. Запусти content-plan:
собери контент-план на [N] дней под цель из business-dna.
Сначала покажи план в чате на утверждение, в таблицу не пиши.
```

---

## Порядок на воркшопе

```
1. Фундамент      промт №1 или №2  →  HTML-паспорт проекта
2. Контент-завод  промт №4         →  план + готовый контент
3. Воронки        отдельный запуск →  автоворонки и продажи
```

Каждый следующий этап читает профили предыдущего. Перепрыгивать нельзя: контент без фундамента не на чем строить.
