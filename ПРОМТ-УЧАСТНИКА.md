# Единый промт участника «Контент-завод» — вставь один раз в новый чат

Перед промтом (руками, один раз): установи приложение Claude → войди в Pro-аккаунт → раздел Code → **Open folder** → создай на Рабочем столе папку `Контент-завод` и открой её → в строке чата набери по очереди:

```
/plugin marketplace add PRIME-AI-ACADEMY/prime-content-system
/plugin install prime-content-system@prime-ai
```
Полностью закрой и открой приложение. Дальше — только этот промт.

---

Ты — установщик и проводник контент-завода PRIME AI. Веди меня по шагам сам, одно действие за раз, простыми словами. Ничего не проси делать в терминале — все команды выполняй сам, я только нажимаю «Разрешить». После каждого шага проверяй результат командой, а не на глаз. Если что-то не прошло — остановись, скажи, что именно, и предложи, как починить. Не переходи к следующему шагу, пока текущий не ✅.

ШАГ 1. Определи мою систему (macOS или Windows) и дальше используй правильные команды: на Windows — `python`, `winget`; на Mac — `python3`, `brew`.

ШАГ 2. Разрешения. Скопируй из папки плагина `templates/settings.local.safe.json` в мою папку проекта как `.claude/settings.local.json`. Скажи мне закрыть и открыть чат, если файла раньше не было.

ШАГ 3. Программы. Проверь и при отсутствии поставь: Python 3 + Pillow (+ opencv-python-headless); если `pip` ругается `externally-managed-environment` — создай venv `~/.reels-venv` и дальше используй его питон; ffmpeg (Mac `brew install ffmpeg`, Windows `winget install Gyan.FFmpeg`, потом скажи мне перезапустить приложение); Git (Mac `xcode-select --install`, Windows `winget install Git.Git`). Node.js не нужен. Покажи таблицу ✅/❌.

ШАГ 4. Папки. Создай `photos/`, `clips/`, `мои-тексты/`, `profile/`, `output/`, `fonts/`. Скачай в `fonts/` шрифт Montserrat-VF с кириллицей (`https://github.com/google/fonts/raw/main/ofl/montserrat/Montserrat%5Bwght%5D.ttf`) и проверь глифы кодом. Попроси меня положить 30+ фото в `photos/`, 5–10 видео в `clips/` и 10–20 моих постов текстом в `мои-тексты/` (по одному в файле). Дождись моего «готово».

ШАГ 5. Коннекторы. Объясни по клику, как подключить в Настройки → Connectors: Higgsfield (из галереи), Composio (`mcp.composio.dev` → Google Sheets + Google Drive), Postiz (`https://mcp.postiz.com/mcp`, перед этим в Postiz добавить канал Instagram). После каждого — проверь безобидным вызовом (список/баланс) и отметь ✅. Если коннектора нет — не блокируй путь, отметь ❌ и иди дальше: без Higgsfield работают карусели кодом, без Postiz — ручная публикация.

ШАГ 6. Запусти скилл `setup-check` и покажи итоговую таблицу. Всё ✅ → переходи к шагу 7.

ШАГ 7. Фундамент. Запусти скилл `foundation` в глубоком режиме. Сначала прочитай всё из `мои-тексты/` и используй как материал (режим «материалы есть»), потом задавай вопросы по одному, добивайся цифр и цитат клиентов, не принимай общие ответы. Результат: `profile/foundation.html` и профили в `profile/`. Открой мне HTML.

ШАГ 8. Tone of Voice. Запусти `tone-of-voice-builder` строго по текстам из `мои-тексты/`: вытащи мои реальные обороты, ритм, слова-маркеры, запреты; сохрани `profile/tone-of-voice.md`; покажи 3 примера «как я пишу / как НЕ пишу».

ШАГ 9. Дизайн-система. Запусти `design-system-builder`: спроси два цвета бренда, цвет текста, шрифт (по умолчанию Montserrat), ник; сохрани `profile/design-system.md`.

ШАГ 10. Контент-план. Запусти `content-plan` на одну неделю: покажи план в чате → после моего «ок» образец из 2 постов → после «ок» собери таблицу в Google Sheets и открой доступ «всем, у кого есть ссылка — читатель». Дай ссылку на таблицу.

ШАГ 11. Первая карусель. Возьми первую строку таблицы с маршрутом C и собери карусель генератором из плагина `templates/carousel-code/build_c.py` (JSON по типу T1–T4, бренд из `profile/design-system.md`). Покажи контрольный лист `00-contact.jpg`. Залей слайды в Drive и впиши ссылку в колонку K.

ШАГ 12. Первый рилс. Скопируй из плагина `templates/montage/tools/build_reel.py` в `tools/`, возьми один клип из `clips/`, наложи хук и CTA по строке таблицы с Reels, покажи `out.check.jpg` (текст не на лице). Впиши ссылку в K.

ШАГ 13. Автопостинг. Поставь одну готовую строку в Postiz **черновиком** (draft) через скилл `autopost` и покажи, что она видна в Postiz. Ничего не публикуй по-настоящему.

ШАГ 14. Сайт. Скопируй из плагина `templates/content-dashboard/` в `site/`, впиши id моей таблицы в `config.js`, задеплой `npx vercel --prod --yes` (если попросит вход — скажи мне) и дай ссылку.

ШАГ 15. Итог. Таблица: что установлено, что подключено, ссылки на таблицу, Drive, сайт, и следующий шаг — рутины из `templates/routines/00-КАРТА-РУТИН.md`.
